01 一句话读懂：联合生成补上「声学可控」这块短板

MM-SONATE 的核心主张：把「可控的音视频联合生成」与「零样本音色克隆」装进同一个流匹配框架。它针对的缺口非常具体——级联式系统（先视频后音频）在细粒度时间对齐上先天吃亏；而现有统一式联合生成模型（如 Ovi）能生成语义相关的声音，却无法控制说话人身份（音色）、无法从参考片段克隆声音，因此无法充当高保真的个性化语音合成器。MM-SONATE 用三件套回应：统一指令-音素输入（unified instruction-phoneme input）强制语言学与时间对齐、音色注入机制（timbre injection）解耦说话人身份与语言内容、以及噪声负条件策略（noise-based negative conditioning）修补多模态场景下标准 CFG 的失效。

论文的自我定位写得很硬：「the first joint generation model capable of zero-shot voice cloning」——第一个能在联合生成框架内做零样本音色克隆的模型。在 VerseBench 上，它在主对比的 11 项指标中胜出 9 项（原文 Figure 1 表述：outperforms baselines (Ovi, CosyVoice2) on 9/11 metrics），尤其在唇同步（SyncNet Confidence 6.51 vs Ovi 4.28）与语音可懂度（WER 0.020，比 JavisDiT 0.256、OpenSora+See&Hear 0.337 低一个数量级）上拉开差距；音色克隆保真度接近专用 TTS 系统，同时还同步生成视频。

深度洞察

问题不在「会不会发声」，而在「声学模态没有旋钮」

联合音视频生成的发展主线一直在同步性上卷（JavisDiT 的层级先验、Ovi 的对称双骨干）。MM-SONATE 换了靶心：当视频侧可以被文本/图像精细控制时，音频侧却只剩「一段语义描述」这种粗粒度旋钮——谁在说、什么音色、什么情绪，既不可指定也不可克隆。这使联合生成器无法进入配音、数字人、个性化内容这类真正需要「声音身份」的场景。把「身份」提升为一等控制变量，是这篇论文对任务定义本身的修订，而不只是模型指标的改进。

02 范式定位：级联 / 联合 / 可控联合

论文在引言里画了一条清晰的谱系。级联派（先生成视频再条件生成音频，如 Diff-Foley、Kling-Foley 一路）的根本困难是时间错位——音频模型以已生成帧为条件，细粒度对齐只能靠后期修补。联合派从 MM-Diffusion（耦合 U-Net，数据仅约 10 小时量级）起步，经 UniForm（单塔拼接 token）、AV-DiT（图像 DiT + 轻量适配器）、JavisDiT（层级时空先验）、SyncFlow（双 DiT + Rectified Flow）、Ovi（对称双骨干强耦合）演化；另一条路是编排预训练单模态专家（MMDisCo 的判别器协作引导、Universe-1 的块级专家拼接）。但如论文所言，多数模型「confined to generating general sound effects or music」——同步语音 + 视频仍是被低估的难题，因为它要求帧级唇音对齐。

音色克隆侧的三条既有范式被论文归纳为：(1) 纯音频 prompt 的上下文学习（保真但特征纠缠、不可控）；(2) 说话人嵌入引导（部分可控）；(3) 文本指令描述目标变化（灵活但未充分探索）。而「跨域（音乐、音效）与多模态生成中的音色克隆」几乎空白——MM-SONATE 正是切这个空档。

深度洞察

音素输入是「对齐问题」的降维打击

唇同步的本质困难是：文本是离散符号、唇动是连续运动，两者的时间对应关系没有显式监督。MM-SONATE 不让模型自己从语义描述里「猜」发音，而是经 G2P 直接给出音素序列——把「何时张口、闭唇、送气」变成可逐帧对齐的确定信号。这解释了 WER 与 SNC 两个数量级式的领先：当对齐先验被写进输入格式，联合生成器不再需要花容量去发现「字怎么读」，可以把容量全部用在「怎么演」。与 Vorch-Human 用角色元数据解「条件语义」相比，MM-SONATE 是在解「内容的时序粒度」——两条互补的表示层路线。

03 系统分解：20B MM-DiT 与「冻结—训练」边界

MM-SONATE 建立在 SD3 式 MM-DiT 架构与流匹配之上：20B 参数、32 层联合扩散 Transformer、RoPE 位置编码、流匹配前馈维 4096；文本侧是前馈维 512 的音素编码器 + Qwen2.5-7B 作为 caption 编码器。音视频 latent 各有专用 codec：音频沿用其先前 SecoustiCodec 框架的 Mel-VAE（mel 编码器/解码器 + 判别器），输入 44.1 kHz 波形、1024 倍下采样得到 43 Hz 嵌入；视频用 CogVideoX 的 3D 因果时序编码器，16× 空间压缩、3 Hz 时间率。

训练边界划得很清楚（原文 Figure 2）：冻结——指令编码器、说话人编码器、视频编解码器、音频编解码器；可训练——各投影器与联合扩散 Transformer。文本模态条件是「时序拼接的指令嵌入 + 音素嵌入」，音视频模态输入是加噪的 mel-VAE latent 与视频 VAE latent。跨模态融合由 MM-Joint Attention 完成：视频 token/视频文本、音频 token/音频文本各自成流，在联合注意力里交换信息。

图 2 · 「冻结—训练」边界图：灰色为冻结模块、彩色为可训练通路。整个模型的可控性创新都发生在「投影器 + 联合 DiT」这一窄腰上——设计哲学是用最小的可训练面撬动最大的条件表达力。

04 统一指令-音素输入与随机模态掩码

MM-SONATE 的「统一」与 Vorch-Human 走的不是同一条路：它不靠 token 元数据，而靠标准化文本模态输入格式。每个任务的文本侧固定为三件套：视频指令描述（完整视觉场景）、音频指令描述（声学属性：性别、年龄、情绪、风格、口音；音乐则为歌手音色、曲风、配器、旋律、情感；音效则为声学场景）、音素序列（语音文本或歌词经 G2P 转换）。对话场景给两个说话人各写一段描述并前置 [S0]/[S1] 区分轮次。

一个关键的语义开关写在原文里：T2VA/TI2VA 里音色只由音频指令描述控制；TA2VA/TIA2VA 里音色来自输入参考音频——且两路可以叠加（参考音频 + 「this woman speaks happily and surprisingly…」这类指令）。多任务能力靠随机模态掩码实现：不把数据切成任务子集，而是对每个完整样本 (文本, 参考图, 参考音) 独立做布尔掩码，被掩掉的模态换成可学习占位 token，优化目标写成 p(V, A | C_active)，C_active ⊆ {c_text, c_image, c_audio}。一次前向同时模拟 T2VA（掩图+音）、TI2VA（掩音）、TA2VA（掩图）、TIA2VA（不掩）。

图 3 · 随机模态掩码把「任务切换」变成「条件开关」：抽象的条件分布 p(V,A|C_active) 被画成一条掩码分发流水线，四种任务共享同一次训练前向。
深度洞察

占位 token 是「缺席」的显式化

缺席模态不是补零、不是遮注意力，而是换成可学习占位 token——「没有参考音频」本身成为一个可训练的表征。这与后续的 CFG 设计有微妙联动：训练里零向量说话人嵌入被定义为「T2VA 模式」的信号（随机/上下文合适的音色），于是「无条件」不再等于「无声学信息」，而等于「走 T2VA 分支」。这个语义混淆正是第 6 节噪声负条件要解决的问题——占位 token 让缺席可见，却也让「无条件」变得有名无实。

批判评估

模态掩码概率「pre-defined」但未公开

论文写明掩码依据「pre-defined probabilities」独立施加、全条件丢弃概率「e.g., 10%」，但各模态的具体掩码概率、以及它们对 T2VA/TI2VA/TA2VA/TIA2VA 混合比例的影响没有给出，也没有消融。任务混合比例会直接决定哪些任务被优先优化（Table 2 里中文 ZH WER 2.768% 明显弱于英文 2.065%，或许与语种/任务配比有关，但论文未分析）。这是复现该训练配方时的最大暗箱。

05 零样本音色克隆：音色注入与多说话人控制

音色注入机制的设计哲学是「简单到可以全序列广播」：预训练（说话人分类任务）的说话人编码器从参考音频抽出全局说话人嵌入 S ∈ RB×D；音素向量 P ∈ RB×L×D 按序列长度把 S 复制上采样到 RB×L×D，然后逐元素相加注入：

Eq.T · 音色注入（原文 4.3.1 节）
$$ P = P + S \in \mathbb{R}^{B \times L \times D} $$
直觉：把「谁在说」作为加性偏置写进每一个音素 token——内容（P 的原始成分）与身份（S）在表示上被显式分解，模型要「用这个音色读这段音素」。对不做克隆的 T2VA/TI2VA，S 直接换成同形状零向量，使两种模式共享同一计算图。替代方案是把参考音频当上下文窗口做 in-context 学习（Chen et al. 一系）——保真但「deeply entangled and uncontrollable」（论文原话），无法单独翻动「身份」旋钮。

多说话人对话再加一层：可学习说话人 ID 嵌入。双人对话时两段话的音素向量 P0/P1 分别吸收各自的说话人嵌入 S0/S1（按各自音素长度上采样）与各自可学习 ID 嵌入 I0/I1：

Eq.D · 多说话人对话控制（原文 4.3.2 节）
$$ P_0 = P_0 + S_0 + I_0 \in \mathbb{R}^{B \times L_0 \times D}, \qquad P_1 = P_1 + S_1 + I_1 \in \mathbb{R}^{B \times L_1 \times D} $$
直觉：S 负责「像谁」（来自参考音频），I 负责「是第几号说话人」（可学习、任务无关）。两者的分工让「同一个人在两段里保持一致」与「两个人不被混淆」成为可分别控制的轴；论文指出 ID 嵌入即使在 T2VA/TI2VA 无克隆任务上也提升控制稳定性——它像 Vorch-Human 的主体索引一样，是「指代绑定」的低层保障。
图 4 · 把「P + S + I」的加性分解画成三条正交控制轴：内容、身份、编号各来自一处、各自可换。抽象的「解耦」由此变成一张可操作的旋钮图。
深度洞察

跨物种克隆暴露了「声音源身份」的抽象层级

定性结果（原文 Figure 7b）显示：以狗叫、羊叫为参考音频时，MM-SONATE 不仅复刻音色纹理，还生成下颌运动与呼吸节律与声学脉冲物理匹配的动物视频。论文由此推断模型学到的是广义「sound source identity」表征，而非人类音素专属的映射。这把音色注入的意义从「TTS 技巧」抬升到「声源身份条件化」：S 向量编码的不是「像哪个说话人」，而是「像哪个发声体」——与语音合成中把 speaker embedding 当作发音器官隐变量的观点遥相呼应。

批判评估

加性注入的表达力上限未被检验

P + S 把全局向量广播到全长序列，天然牺牲时变音色（情绪起伏、耳语—喊叫转换、同一句内的音色漂移）；指令描述虽然可以叠情绪，但那是「换一段风格」而非「沿时间轴调制」。对照 Vorch-Human 把音色参考作为独立 token 组参与注意力（可被逐帧检索），加性注入更省参数但更「钝」。论文自己也承认：低质量、含噪参考音频下，模块难以把背景噪声与音色解耦。

06 噪声负条件：标准 CFG 在声学侧为什么失效

这是全文最有「研究味」的一节。标准 CFG 用条件估计与无条件估计外推：

Eq.2 · Classifier-Free Guidance（原文式 (2)）
$$ \tilde{\epsilon} = \epsilon_{uncond} + w \cdot (\epsilon_{cond} - \epsilon_{uncond}) $$
直觉：w 是引导强度；传统做法把无条件分支构造为 null 字符串或负提示。但 MM-SONATE 的声学条件走说话人编码器，负提示必须跨出文本域。关键发现：零向量负嵌入是语义错位的——训练里 S=0 专指 T2VA 任务（从文本生成随机/上下文合适的音色），所以拿零向量当负条件，只是让模型「远离随机音色模式」，而不是「远离低质量音频」。

论文的替代方案：把自然采集噪声喂进预训练说话人编码器，得到负说话人嵌入 S_neg——在嵌入空间里对「无结构声学特征」形成排斥力。为找最优负先验，论文系统扫了八种策略：零向量基线、六档递进能量的高斯白噪声、自然采集白噪声。结果（原文 Figure 4/5）：自然噪声拿下最低 WER 2.06%（最差设置 3.17%，相对改善 1.11%），代价仅是 SyncNet 置信度从最优 6.12 微降到 5.94（−0.18），说话人一致性保持稳健（各策略间 0.813–0.815 量级，差异甚微，论文表述）。论文用流形假说解释：自然噪声比合成高斯或零向量更接近训练数据里真实背景噪声的分布，说话人编码器把它映射到嵌入空间中更「有意义」的区域，从而给流匹配一个更有效的「负参考」。

图 5 · 把「负条件选谁」画成嵌入空间里的站位问题：零向量指向任务语义（T2VA），自然噪声才指向「低质量/无结构」的排斥方向。CFG 这个被当作默认开关的组件，在多模态条件下变成了一个必须显式设计的自由度。
深度洞察

「无条件」在多任务训练下是一个被污染的概念

这节的深层教训超出本文：当训练用占位/零嵌入编码「某模态缺席」时，无条件分布与「某种任务模式」发生了语义碰撞。CFG 的外推方向 ε_cond − ε_uncond 因此不再指向「质量轴」，而指向「任务轴」。MM-SONATE 用「更真实的负样本」绕开碰撞；更彻底的解法或许是给无条件分支一个独立于任务编码的专用表征。凡是用条件嵌入做任务路由的模型（包括 Vorch-Human 的角色嵌入路线）都应检查同类污染——这是一个可迁移的设计教训。

深度洞察

能量扫描被浪费了：真正的变量是「分布真实性」

六档高斯能量的扫描结果几乎平坦（WER 2.53–3.17% 无单调规律，SNC 变化 ≤ 0.08），说明负嵌入的 RMS 能量不是有效旋钮；换到自然噪声（能量未必更高）后 WER 才显著改善。这提示说话人编码器的输入分布先验主导了嵌入几何——与其调负样本的「音量」，不如调负样本的「出身」。对做条件扩散的实践者：负条件应当从训练数据的真实退化分布中采样，而不是用数学上方便的零/高斯。

07 数据策略：合成音色数据集 + 一亿对齐语料

零样本音色克隆要求把「音色」从情绪、背景噪声等声学因素中解耦出来，同时保持身份相似度——为此论文造了一条严苛的合成数据流水线（原文 Figure 3）：从内部仓库采样原始语音/音乐 → 类别分类（speech/song）→ 专有分离工具去噪、从音乐提取干声（保证参考音色无环境残留）→ 用 DMP-TTS（零样本 TTS）以预定义的情绪中性文本合成语音并显式指令生成中性风格（消除情绪泄漏）→ WavLM-large 说话人验证计算合成语音与真值提示的说话人嵌入余弦相似度，低于严格阈值即丢弃。第二块是约 1 亿对齐样本的多模态预训练语料：每条是 (视频, 音频, caption, 转写/歌词) 四元组，覆盖人声、环境音效、音乐，时长 3–15 秒，音频 16–44.1 kHz，视频 240p–720p，标注全部由专有自动工具生成或校验。

图 6 · 把「合成音色数据集」画成五级漏斗并标注每级的解耦目的（去环境、去情绪、验身份），再与亿级语料并置成「保真 vs 通用」的双轨数据策略。
情绪泄漏的处理
用预定义中性文本 + 显式中性风格指令合成，让「音色」通道里只剩身份。替代方案：直接用野外数据训练音色编码器——情绪/噪声与身份纠缠，克隆时会把情绪一起抄走。
身份保真过滤
WavLM-large 说话人验证 + 严格余弦阈值，合成样本与真值提示不一致即弃。替代方案：只靠 TTS 模型自评——自评与人耳的身份感知经常脱节。
四元组对齐语料
(视频, 音频, caption, 转写/歌词) 全对齐；转写/歌词使 G2P 音素监督可得——这是 WER 0.020 的数据地基。替代方案：无转写的音视频对——音素监督缺失，唇音对齐只能靠弱相关信号学。
时长/分辨率档位
3–15 s、240p–720p、16–44.1 kHz：覆盖广但均属短片段——与局限「长内容仍具挑战」互为因果。

09 深度洞察与批判评估：可控联合的代价与边界

把 MM-SONATE 放回两条研究脉络的交汇点看：它一边继承联合生成的同步性红利，一边移植 TTS 的条件化技术（说话人嵌入、G2P、零样本 prompt）。其独有贡献不是单点指标，而是证明「联合生成器可以兼任个性化语音合成器」这条路走得通。代价与边界同样清晰。

深度洞察

三种控制条件的「语义正交性」是可控联合的设计准则

MM-SONATE 的条件栈可以按语义轴拆开：文本/音素管内容，音频指令管风格属性，参考音频（S）管身份，ID 嵌入（I）管指代，首帧管视觉初始状态。加性分解（P+S+I）与拼接分解（指令+音素）共同保证各轴尽量正交。对照之下，纯 prompt 方案把所有轴塞进一段自然语言（纠缠且不可靠），纯 in-context 方案把内容与身份绑死。这条「先正交化、再注入」的准则，与 Vorch-Human「先解耦 driving/voice、再统一编排」是同一种设计哲学在不同层的实现。

深度洞察

跨物种克隆是「泛化」的免费探针

狗叫/羊叫克隆不是噱头：它是模型「音色通道 = 声源身份而非人类说话人模板」的反事实证据。如果音色注入只是记忆了人类说话人簇，跨物种输入应落到簇外而失败；实际却连下颌运动都跟着声学脉冲走，说明 S 的语义是发声体级的。这对评估零样本方法是一个启示：跨域/跨物种测试用例能便宜地探测表示的抽象层级，比再多一组 SIM-o 数字更有诊断力。

批判评估

技术局限（论文自陈）与结构性短板

论文自陈四条：3–15 秒外长内容语义/时序一致性待解（需长上下文注意力或自回归外推）；高压缩损失高频细节（纹理瑕疵、音乐瞬态）；极端头姿/快速运镜/重遮挡下唇部失同步或伪影；低质量参考音频下音色与噪声难解耦。结构性短板还包括：20B 规模 + 1 亿私有语料 + 专有分离/标注工具使复现门槛极高；评测仅 VerseBench 单一基准；多说话人对话通过率比单人低约 10 个百分点，说明「多说话人 × 长对话」仍是开放问题。此外流匹配目标写作 u_t(x|x1) = x1 − (1−t)x0（论文表述）——标准 OT 路径的速度场通常为 x1 − x0，此处式形存疑，读者实现时应回归 x_t = t x1 + (1−t)x0 的标准推导核对。

批判评估

安全机制是这篇论文少见的「做实」部分，但仍是猫鼠游戏

与多数论文的立场声明不同，MM-SONATE 给了具体机制：输入/输出双向安全分类器、高风险公众人物生成限制、参考音色使用权验证（探索中）、抗压缩/裁剪的不可见水印、API 分级访问而非开放权重。值得肯定。但水印的鲁棒性没有给出量化（抗攻击成功率未报），「限制高风险人物」的判定标准未披露——深度伪造防护的可验证性仍然缺位。

10 自主科研问题

以下问题聚焦「多模态可控 + 零样本音色克隆」交叉处的理论空白与可操作路线。

自主科研问题 · Q1

加性音色注入 P+S 的表达力边界与时变音色缺失

未知与意义：全局向量广播保证了「同一音色贯穿全长」，但真实语音的音色随情绪、气声、喊叫沿时间变化；P+S 是否系统性抹平了这些变化、能否扩展为逐帧 S_t，未知。

理论分析：把音色视为发音器官的隐变量轨迹 s(t)，P+S 等于对 s(t) 施加常数约束；若生成分布需要非平凡 s(t)，则模型只能在残差里偷偷编码时变信息，造成「指令情绪」与「参考音色」的隐性冲突。

连接：与风格迁移中的全局/局部风格调制（AdaIN vs 动态滤波）、语音合成中的 prosody 探针、可控生成的解耦表征理论相连。

探究方向：构造同句内情绪转换的测试集，测 P+S vs P+S(t)（时变注入）的音色轨迹保真；用线性探针检查残差是否携带时变音色；尝试把参考音频切窗提取 S_t 序列并做插值注入。

自主科研问题 · Q2

CFG 负条件的「语义污染」能否被一般化地检测与修复？

未知与意义：零向量负嵌入因与 T2VA 任务模式重合而失效，靠自然噪声缓解；但「无条件分布被任务编码污染」是所有条件嵌入式路由模型的通病，目前只有个案发现、没有诊断工具。

理论分析：若无条件表征 e_∅ 与任务模式表征 e_task 的内积不为零，CFG 外推方向就混入任务轴分量；可定义「条件正交性度量」预测 CFG 的失效程度，并要求 e_∅ 与所有 e_task 正交。

连接：与 CFG 的理论分析（能量视角/贝叶斯视角）、概念擦除（concept erasure）、对抗样本的负空间设计相通。

探究方向：在 Vorch-Human 式角色嵌入、指令调制模型上复现同类失效；扫不同负表征（零/高斯/自然噪声/学习负嵌入）拟合「负样本真实性 vs 生成质量」曲线；设计与任务编码正交的无条件分支并对比。

自主科研问题 · Q3

「声音源身份」表征的抽象层级：跨物种克隆的机理

未知与意义：跨物种克隆（狗叫/羊叫）暗示 S 编码发声体级身份，但没有证据说明它编码的是「声源物理」（声道形状、下颌运动）还是「频谱纹理」——两者对未来可控性含义完全不同。

理论分析：若 S 近似编码发声器官隐变量，则换 S 应连带改变生成视频中的口型/下颌动态（论文定性观察到）；若只编码频谱统计，则视觉侧不应随 S 系统变化。这是一个可证伪的干预实验。

连接：与语音产生机理建模（声源-滤波器理论）、音频-视觉因果表征、解耦生成的干预式评估（do-操作视角）相连。

探究方向：固定文本/指令、只干预 S，测视频中口型参数的响应；对 S 做属性探针（性别/年龄/体型/物种）；尝试用声学物理参数回归 S 的可解释方向。

自主科研问题 · Q4

音素约束与联合生成的容量分配：谁为唇同步买单？

未知与意义：WER 0.020 / SNC 6.51 的领先被归因于音素输入，但没有消融（音素 vs 纯文本；音素 + 粗时间戳 vs 音素无时间戳）拆分贡献，也没有测量音素监督占用的模型容量对画质（MS 0.48 落后 Ovi）的挤压。

理论分析：音素序列提供了近乎确定的内容-时间对应，模型可把容量从「发现发音」转向「渲染表演」；但总容量有限，若同步约束过强，可能以牺牲运动丰富度为代价（MS 落后或非偶然）。

连接：与多任务容量竞争、可控生成中的控制强度-多样性权衡、信息瓶颈视角下的条件带宽研究相连。

探究方向：做「文本/音素/音素+时长」三档输入消融，测 WER-SNC-MS 三维权衡曲线；扫描音素条件的丢弃率观察容量再分配；用梯度/注意力分析看音素 token 占据的容量份额。

自主科研问题 · Q5

合成音色数据的「过滤阈值—克隆泛化」权衡曲线

未知与意义：WavLM 相似度阈值越高数据越纯，但可用说话人/音色多样性越窄；阈值如何影响零样本克隆对「分布外音色」的泛化，论文未给扫描。

理论分析：过滤是偏差-方差交易：阈值过高 → 训练音色流形变窄 → 分布外参考的嵌入外推失效；阈值过低 → 身份噪声监督 → 克隆相似度上限下降。最优阈值应随目标泛化域而变。

连接：与数据筛选（data curation）对泛化的影响、零样本学习的支撑集多样性理论、噪声标签学习相连。

探究方向：按阈值分档训练小型复现模型，扫 SIM-o 对参考音色距离的响应曲线；报告「可用说话人数 vs 泛化半径」的帕累托前沿；探索软权重（按相似度加权）替代硬阈值。

# 音色注入 + 多说话人 + 随机模态掩码 —— 复原自 4.3/4.4 节
def build_text_conditions(sample, mask_probs, training=True):
    # sample: 视频指令、音频指令、文本/歌词、参考图、参考音频、说话人分段
    phonemes = g2p(sample.text_or_lyrics)                # G2P → 音素序列
    P = phoneme_encoder(phonemes)                        # ∈ R^(B×L×D), FFN 512
    if sample.ref_audio is not None:                    # TA2VA / TIA2VA
        S = speaker_encoder(sample.ref_audio)            # 冻结，∈ R^(B×D)
    else:
        S = zeros(B, D)                                  # T2VA/TI2VA：零向量 = 「随机音色」任务信号
    P = P + upsample_to_len(S, L)                        # 式: P = P + S
    if sample.num_speakers > 1:
        P_k = P_k + upsample_to_len(ID_emb[k], L_k)      # 每话轮再加可学习 ID 嵌入
    instr = concat(video_caption, audio_caption, P)      # 统一指令-音素输入
    if training:
        for m in (c_image, c_audio):                      # 随机模态掩码
            if rand() < mask_probs[m]:
                m = learnable_placeholder[m]             # 缺席模态 → 可学习占位 token
        if rand() < 0.10:
            cond = learnable_placeholder[ALL]            # 全丢 → 近似无条件（CFG 用）
    return instr, cond

# 噪声负条件 CFG + Euler 积分采样 —— 复原自式 (1)(2) 与 6.1/6.4.1 节
def sample_av(model, cond, neg_strategy="natural_noise", w=5.0, steps=20):
    # 流匹配 OT 路径 x_t = t·x1 + (1−t)·x0；推理用 Euler、步长 0.05
    x = randn_like(audio_video_latents)
    S_neg = None
    if neg_strategy == "zero":
        S_neg = zeros_like(cond.S)                       # 语义错位：指向 T2VA 而非低质量
    elif neg_strategy == "natural_noise":
        S_neg = speaker_encoder(natural_white_noise())   # 流形假说：更真实的负先验
    cond_neg = cond.with_speaker(S_neg)                  # 负分支只换声学条件
    for t in arange(0.0, 1.0, 0.05):
        e_c = model(t, cond,     x)                      # 条件估计
        e_u = model(t, cond_neg, x)                      # 「无条件」估计
        e   = e_u + w * (e_c - e_u)                      # 式 (2): ε̃ = ε_uncond + w(ε_cond − ε_uncond)
        x   = x + 0.05 * e                              # Euler 步
    return video_decoder(x.v), audio_decoder(x.a)        # 3D 因果 VAE / Mel-VAE（均冻结）

如果只记住三件事：① 统一指令-音素输入把「说什么」精确到音素、把「什么声学属性」交给指令、把「谁说」交给参考音频——三种条件语义正交；② 音色注入 P+S(+I) 是加性解耦，零样本克隆由此免费获得、并泛化到跨物种发声体；③ 标准 CFG 的「无条件」在任务编码下会被污染，自然噪声负先验是便宜有效的修补——但克隆保真仍逊于专用 TTS，长内容、极端姿态、可复现性都是未偿债务。
