01 一句话读懂 JoyStreamer

JoyStreamer 要解决的是音频驱动数字人的「文本失语症」：模型能把口型对得很准，却做不出提示词里写的复杂动作——搬椅子、爬梯子、镜头环绕、背景转场。它的答案不是去收集更难的数据，而是把「文本可控性」当作一种可以从视频基础模型中蒸馏迁移的能力：在 DMD 后训练里同时挂上「音频教师」与「文本教师」（Twin-Teacher），再用按去噪时间步调度的动态 CFG 把音频与文本两个条件在时间轴上错峰使用。

论文出自京东科技（JD Technology），基于 Wan2.2-T2V-14B 基础模型构建，自采约 4,000 小时说话/演讲/唱歌数据，支持长时序、全身动作、运镜控制、多人对话与非人主体角色扮演。GSB 主观评测中优于 OmniHuman-1.5 与 KlingAvatar 2.0（论文表述）。

深度洞察

「能力迁移」取代「数据扩容」：教师模型即隐式数据集

传统思路遇到「文本控制弱」会去造数据（Wan-S2V 式精细标注数据策展），但复杂运动/运镜数据极难收集且常被清洗流程滤掉。JoyStreamer 换了一个等价视角：视频基础模型（Wan2.2-I2V-14B）本身就「见过」海量带复杂动作标注的文本-视频对，它的 score 估计就是一个活的、无限大的复杂运动数据分布。把教师塞进 DMD 的 real score 里，等于让学生在一个「文本对齐分布」上做分布匹配——这是一种把后训练框架（DMD）当作能力移植接口的用法，而非常规的加速蒸馏用法。

02 范式定位：两大病根——数据偏置与模态冲突

论文对「文本失语症」的归因有两条主线，这两个诊断决定了后续两个技术设计的分工。其一是数据偏置（Data Bias）：训练数据绝大多数来自演讲、脱口秀、主持等相对静态的场景，缺少动态运镜与大位移肢体动作；随着训练推进，模型过拟合到「说话风格」的窄分布，文本指令中指定大动作的执行能力被逐步侵蚀。其二是模态冲突（Inter-Modality Conflicts）：模型同时被参考图、音频、文本驱动，音频主要掌控节奏性动态，参考图隐式约束运动幅度，两者共同引入竞争性归纳偏置，干扰文本对动作模式的控制。

图 1 · 把「文本控制弱」这一模糊现象拆成两条可分别处方的因果链：分布层面的过拟合与条件层面的竞争（依据论文 Sec.1 归因与 Sec.3.3 对策绘制）。

对比同期路线可以看出定位差异：Wan-S2V 用精心标注的数据维持文本可控性，但论文指出其 reference latent 的使用严重限制了运动动态；KlingAvatar 把问题重构为首尾帧条件生成，但易产生重复运动或违反物理规律的轨迹（论文观察到行走数秒后方向突变，推测其缺少对 motion frames 的显式建模）；OmniHuman-1.5 / KlingAvatar 2.0 文本遵循较好，但在人-物交互等复杂指令上仍有明显缺口。JoyStreamer 选择在后训练阶段「借力」基础模型，而不是与数据管线较劲。

深度洞察

范式之争的本质：约束放在哪里

Wan-S2V 把文本可控性约束放在数据上，KlingAvatar 把它放在输入接口（首尾帧）上，JoyStreamer 把它放在训练信号（双教师 score）上。数据约束昂贵且不可扩展，接口约束会把运动锁死在插值先验里，而训练信号约束只需换一个教师模型就能升级——这解释了为什么 JoyStreamer 声称「不引入任何新训练数据」也能获得文本可控性，也暗示了它对教师质量的强依赖（教师换代即模型换代）。

03 系统分解：预训练流水线与架构

预训练分两阶段。第一阶段只训练 FramePack 模块与基础模型的自注意力层，目标是获得可无限时长生成的基座模型；第二阶段插入音频交叉注意力层，用预训练 Wav2Vec2 编码音频特征并注入，实现精确的音频驱动口型同步。两阶段完成后，该模型即作为 DMD 后训练阶段的音频教师。

图 2 · 把「无限时长生成 + 口型同步 + 文本控制」三个目标折进一条 latent 流水线：FramePack 负责段间连续，音频交叉注意力负责口型，而文本控制留待后训练阶段强化。
Latent 与解码
3D VAE（来自 Wan2.2）把视频映射到紧凑 latent 空间；除末帧外加噪。推理时把参考图当伪末帧注入，位置索引在原索引上+10，防止模型严格回退到末帧、换取更丰富的运动动态；完成后丢弃 motion frames 与伪末帧的 latent，单次推理产出 76 个可用视频帧（论文表述）。替代方案：首帧锚定（易 attention sink、身份漂移）或纯 reference latent（如 Wan-S2V，论文认为其限制运动动态）。
训练与前置
基础模型 Wan2.2-T2V-14B；motion frames 长 9、video frames 长 80；预训练 AdamW、学习率 2e-5、全局 batch 64，分别基于 Wan2.2 的 high-expert 与 low-expert 派生模型训练（论文表述）；数据为自采约 4,000 小时（真人与卡通角色的说话/演讲/唱歌）。替代方案：从头训练音频条件模块；论文选择冻结大部分、仅插入音频交叉注意力。
Prompt Engineering 模块
基于 Qwen3-VL-32B 优化的 PE 模块，按音频时长自适应产出文本片段：每 3.24 秒输入音频多产一个片段，最多 5 个，按时序语义分配到不同生成段，避免跨段重复动作（论文表述）。替代方案：整段共用同一 prompt（会诱发段间动作重复）。
免训练多人对话
检测器出二值 mask，在音频交叉注意力里按人分区：某人的音频 token 只与该人 mask 内区域做交叉注意力，mask 为 0 的区域用静音音频做注意力。无需训练即可支持 3 人以上与多轮对话（论文表述）。
Ref / Last Frame→3D VAE Enc.→FramePack（9 帧运动 latent）→时间维拼接→DiT + 双 Cross-Attn→3D VAE Dec.

04 关键公式：DMD 与 Twin-Teacher 的 score 重构

后训练采用 DMD（Distribution Matching Distillation）框架。DMD 的梯度把学生生成器往「real score 与 fake score 之差」的方向推：real score 来自教师、fake score 来自学生自身的 EMA 副本（论文表述）。先把公式摆清楚，再看双教师如何改写 real score。

Eq.1 · DMD 梯度（论文式 1）
$$ \nabla_\theta \mathcal{L}_{\mathrm{DMD}} = \mathbb{E}_{z_t,\tau,\mathbf{x}_\tau}\left[ -\left( s^{\mathrm{real}}_{\mathrm{cond}}(\mathbf{x}_\tau) - s^{\mathrm{fake}}_{\mathrm{cond}}(\mathbf{x}_\tau) \right) \frac{\partial G_\theta(z_t)}{\partial \theta} \right] $$
直觉：$G_\theta$ 为 avatar 生成器，$z_t$ 是噪声级 $t$ 下的输入，$\mathbf{x}_\tau$ 是把 $G_\theta$ 的去噪输出重新加噪到噪声级 $\tau$ 的结果。梯度方向即「教师认为该往哪去 − 学生自己认为在哪」，本质是把分布匹配问题化归为 score 差驱动的回归。

原始 DMD 里 real score 是单教师的 CFG 组合：以预训练得到的音频基础模型 $\epsilon_{\mathrm{audio}}$ 为核，分别沿音频、文本两个条件方向做差分。

Eq.2 · 常规 DMD 的 real score（论文式 2）
$$ \begin{aligned} s^{\mathrm{real}}_{\mathrm{cond}}(\mathbf{x}_\tau) =\; & \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{un\text{-}text}}, c_{\mathrm{un\text{-}audio}}) \\ +\; & \alpha_a \cdot \left( \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}},c_{\mathrm{audio}}) - \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}},c_{\mathrm{un\text{-}audio}}) \right) \\ +\; & \alpha_t \cdot \left( \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}},c_{\mathrm{un\text{-}audio}}) - \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{un\text{-}text}},c_{\mathrm{un\text{-}audio}}) \right) \end{aligned} $$
直觉：$c_{\mathrm{text}}, c_{\mathrm{audio}}$ 为文本/音频条件，$c_{\mathrm{un\text{-}text}}$ 为负提示条件，$c_{\mathrm{un\text{-}audio}}$ 通常为零嵌入（空音频）；$\alpha_t, \alpha_a$ 分别是文本与音频 CFG 引导尺度。结构是「无条件底 + 音频方向增量 + 文本方向增量」的两级差分。问题在于 $\epsilon_{\mathrm{audio}}$ 对文本条件生成的监督天生不准。

双教师的改写只动了两处：把音频方向差分的「负项」换成文本教师 $\epsilon_{\mathrm{text}}$（预训练 Wan2.2-I2V-14B），把文本方向差分的「正项」也换成 $\epsilon_{\mathrm{text}}$。论文分别命名为 audio condition engine 与 text condition engine。

Eq.3 · Twin-Teacher real score（论文式 3）
$$ \begin{aligned} s^{\mathrm{real}}_{\mathrm{cond}}(\mathbf{x}_\tau) =\; & \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{un\text{-}text}}, c_{\mathrm{un\text{-}audio}}) \\ +\; & \alpha_a \cdot \underbrace{\left( \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}},c_{\mathrm{audio}}) - \epsilon_{\mathrm{text}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}}) \right)}_{\text{audio condition engine}} \\ +\; & \alpha_t \cdot \underbrace{\left( \epsilon_{\mathrm{text}}(\mathbf{x}_\tau,\tau,c_{\mathrm{text}}) - \epsilon_{\mathrm{audio}}(\mathbf{x}_\tau,\tau,c_{\mathrm{un\text{-}text}},c_{\mathrm{un\text{-}audio}}) \right)}_{\text{text condition engine}} \end{aligned} $$
直觉：$\epsilon_{\mathrm{audio}}$ 是预训练基座（音频教师），$\epsilon_{\mathrm{text}}$ 是新引入的文本教师。文本方向的「监督锚点」由音频教师的空条件估计换成了文本教师的文本条件估计——文本可控性由此被显式写进 score 目标，学生在分布匹配压力下被迫继承基础模型的复杂动作先验。
深度洞察

Eq.3 的几何含义：把教师分歧投影成两个模态引擎

Eq.2 与 Eq.3 的差别可以读成向量替换：音频引擎从「同教师内的音频差分」变为「音频教师整体 − 文本教师」，即两位教师之差被定义为音频条件带来的净增量；文本引擎则是「文本教师 − 音频教师的无条件底」，即文本教师带来的净增量。这把教师间的分歧显式分解为两个正交方向的监督信号——但代价是当两位教师对同一 $\mathbf{x}_\tau$ 的 score 估计严重不一致时，两个引擎会互相放大噪声（对应论文观察到的时序稳定性下降，见第 09 章批判评估）。

图 3 · 双教师 DMD 的关键不是「多一个教师」，而是把两位教师的 score 之差定义成两个模态引擎——这使「文本可控性」成为一个可被梯度直接优化的显式目标。

05 动态 CFG：按去噪时间步给模态「错峰放权」

模态冲突的化解思路借自 AlignHuman 的观察：全局运动结构在高噪声（早期）去噪步就已确立，细节在低噪声（后期）步精修。据此，双教师 DMD 训练中文本与音频的 CFG 尺度按时间步分段调度：当去噪时间步超过 $t_{\mathrm{spot}}$（通常设为 950）时，把音频 CFG 尺度 $\alpha_a$ 设为 0.1，让文本条件优先决定全局运动；时间步低于 $t_{\mathrm{spot}}$ 后把 $\alpha_a$ 提到 4.0，确保口型精度（以上系数均为论文表述）。

Eq.4 · 动态 CFG 调度（依论文 Sec.3.3 参数整理）
$$ \alpha_a(t) = \begin{cases} 0.1, & t > t_{\mathrm{spot}} \approx 950 \quad \text{（高噪声段：文本优先定全局动作）} \\ 4.0, & t \le t_{\mathrm{spot}} \quad \text{（低噪声段：音频优先保口型）} \end{cases} $$
直觉：把「谁在生成的哪个阶段说了算」变成显式调度表。文本管宏观（动作模式、运镜、场景），音频管微观（口型、节奏）。$\alpha_t$ 的具体取值论文未给出；$t_{\mathrm{spot}}$ 论文表述为「typically set to 950」，未附敏感性分析。
图 4 · 把「模态冲突」这一静态问题重写为时间轴上的调度问题：文本与音频不必在同一去噪阶段竞争同一运动决策权。

此外论文报告了一个工程细节：只用 Eq.3 训练的模型文本响应显著增强，但生成视频的时序稳定性下降；为此在双教师 DMD 之后追加一轮基于 Eq.2 的 vanilla DMD 训练来恢复视觉-时序连贯性。这一「先激进后保守」的两段式后训练配方值得记住——它意味着 Eq.3 引入的分布偏移是真实存在的，需要一个稳定化回合来对冲。

深度洞察

时间步调度与「粗到细生成」的深层同构

扩散生成的「先布局后精修」特性此前多被用在结构引导（如 AlignHuman 的时间步分段偏好优化）上。JoyStreamer 把它用于多条件仲裁：既然运动模式在高噪声段定型，那么让音频在该段以 0.1 的尺度「近乎闭嘴」，就等于承认「口型同步是低频决策之后的高频修正」。这一安排与人类表现力生成的因果顺序一致——先决定「做什么动作、镜头怎么走」，再决定「哪一帧哪个口型」。反过来也解释了为什么静态说话场景不需要这么强的调度：那里文本与音频的决策本来就同频。

批判评估

$t_{\mathrm{spot}}$ 与 $\alpha$ 配置缺乏敏感性证据

$t_{\mathrm{spot}}\approx 950$、$\alpha_a\in\{0.1, 4.0\}$ 都以「typically」口吻给出，论文没有报告分界点扫描、$\alpha_t$ 取值或不同视频长度/分辨率下的最优配置差异。考虑到这两个数直接决定「文本控制力」与「口型保真」的分配比例，缺这组消融使结论难以迁移到别的噪声调度（例如不同的 flow matching 离散化）。

06 免训练多人对话：用注意力掩码给音频「分座位」

多人对话是 JoyStreamer 的招牌应用之一，且完全免训练。机制拆开看只有两步：检测器给出各主体的二值 mask（检测区域为 1、其余为 0）；在音频交叉注意力中，查询来自视频 latent、键值来自多路音频嵌入，某人的音频 token 只与该人 mask 区域内的视频 token 计算交叉注意力，mask 为 0 的区域则用静音音频参与注意力计算。

图 5 · 「谁说话谁驱动谁」被实现为一次注意力路由手术：不改权重、不加训练，只在交叉注意力里按空间掩码分配音频源。

相比需要大量多人视频训练数据、训练成本高且难以扩展到更大群组、也难以处理多轮对话的既有方案（如 Let Them Talk 类方法，论文表述），这条路线把多人能力从「模型容量问题」降维成「推理时路由问题」。它的代价也直白：硬掩码边界上两个人的运动（牵手、递物、遮挡）无法交叉建模，检测器的漏检/误检会直接变成音画错配。

深度洞察

注意力即路由：一种可移植的「组合式能力」范式

这套掩码机制本质上把音频交叉注意力当成了可编程的交换机——只要基座有音频交叉注意力接口，多人能力就能即插即用（论文称其可快速适配到任意音频驱动视频生成基座）。这与 JoyStreamer 整体的设计观一致：能力不一定非要写进权重，也可以写进推理时的计算图结构。跨论文看，这与 Beyond Monologue 用注意力先验（高斯核）写入「倾听需要长程上下文」的物理直觉形成有趣对照：一个改注意力的路由，一个改注意力的度量。

07 训练、推理与超参清单

预训练（两阶段）
阶段一：仅训 FramePack 模块 + 基础模型自注意力层，得无限时长基座；阶段二：插入音频交叉注意力（Wav2Vec2 编码），训出精确口型同步。AdamW，学习率 2e-5，全局 batch 64。
后训练（DMD 两段）
第一段：Twin-Teacher DMD（Eq.3 + 动态 CFG），以 LoRA 微调音频投影层、音频交叉注意力层与自注意力层，学习率 1e-5；第二段：追加一轮 vanilla DMD（Eq.2）恢复时序稳定性。
推理
参考图作伪末帧、位置索引 +10（简单提示词场景为 +3，以减少多余动作）；完成后丢弃 motion frames 与伪末帧 latent，单次推理 76 个可用帧；PE 模块按每 3.24 秒音频产出至多 5 个时序提示片段。
数据
自采约 4,000 小时，覆盖真人与卡通角色的说话、演讲、唱歌。复杂动作/运镜数据不在训练集中——这正是双教师要补的缺口。
预训练阶段一→预训练阶段二（+音频）→Twin-Teacher DMD + 动态 CFG→vanilla DMD 稳定化→推理（伪末帧 + PE）

一个容易被忽略的推断细节是位置索引 +10：如果参考图严格占据末帧位置，模型会倾向于「收敛回」参考图、压制运动幅度；把索引往后挪 10 位，参考图变成「时间轴上更靠后的锚」，生成窗口反而更敢动。同一旋钮在简单提示词评测里被收紧到 +3（论文表述）——同一个模型靠一个整数就能在「表现力」与「克制」之间切换，说明可控性并没有均匀地长在权重里，而是部分悬挂在接口约定上。

08 优势与证据

证据分两层：GSB 主观评测（96 个精心构造的测试例，覆盖表情、肢体、人-物交互、运镜、背景转场，含大量超过 30 秒的长音频；评分 $(G+S)/(B+S)$）与定量基准（90 个相对静态的说话/演讲/唱歌例，考口型与身份）。

09 深度洞察与批判评估

深度洞察

「零新数据」承诺的真正含义

论文的 headline 贡献是「without introducing any new training data」获得文本可控性。严格说这不是零成本——它把数据成本转化成了教师推理成本（每次 DMD 更新都要跑 14B 文本教师 + 音频教师的多分支前向）与教师偏差风险（学生只能学到教师分布内支持的动作）。但对工程方这是极划算的交易：不用清洗、标注、筛选海量复杂运动数据，升级只需换教师。这条「数据→教师」的成本转换路线，可能是后训练时代比模型架构更值得关注的迁移范式。

深度洞察

表现力的「可调旋钮」暴露了能力的外置

伪末帧索引偏移（+10 / +3）与 PE 模块（每 3.24 秒一个片段、上限 5 个）都是推理期旋钮，且显著影响结果（运动幅度、动作重复率）。这说明 JoyStreamer 的「高表现力」并非完全内化于权重，而是权重 × 接口约定的联合产物。对复现者来说这是双刃剑：文档化充分则易用，文档缺失则效果不可复现。

批判评估

Eq.3 换来的时序稳定性损失需要「二次治疗」

论文自述：只用 Eq.3 训练会「显著提升文本响应但降低时序稳定性」，须追加一轮 vanilla DMD（Eq.2）恢复连贯性。这暴露双教师差分目标并非无偏——当 $\epsilon_{\mathrm{audio}}$ 与 $\epsilon_{\mathrm{text}}$ 对同一 $\mathbf{x}_\tau$ 的 score 估计分歧大时，两个模态引擎的方向噪声会污染梯度。追加稳定轮次是有效的工程补丁，但也意味着最终模型的文本可控性被部分「回吐」，论文未量化回吐幅度。

批判评估

证据体系的三处软肋

其一，GSB 主观评测的两个对手（OmniHuman-1.5、KlingAvatar 2.0）均为闭源模型，无法控制采样参数与版本，对比可复现性弱；其二，96/90 个测试例为自建集合，文本提示由作者构造，与 PE 模块的训练分布可能同源，存在评测偏置风险；其三，HKV 全表最低（32.15 vs 48.41/47.65/58.76），论文以「索引 +3 抑制动作」解释但未做同一模型 ±索引的对照实验——若该解释成立，应能看到 +10 时 HKV 回升，这组数据缺席。

批判评估

复现成本与适用边界

14B 级基础模型 + 双教师 DMD + LoRA 后训练 + 4,000 小时自采数据，普通实验室难以复现；免训练多人对话虽轻量，但依赖检测器质量，硬掩码无法建模人物间交互动作（递物、接触）；此外「非人主体角色扮演」「多人对话」等能力主要以定性样例展示（论文表述），缺乏定量基准。

10 自主科研问题

自主科研问题 · Q1

双教师 score 分歧何时有害？模态引擎的梯度冲突度能否自适应调节 $\alpha_a,\alpha_t$？

未知与意义：Eq.3 把音频引擎定义为 $\epsilon_{\mathrm{audio}}(\cdot,\mathrm{text},\mathrm{audio}) - \epsilon_{\mathrm{text}}(\cdot,\mathrm{text})$。当两位教师对同一 $\mathbf{x}_\tau$ 的 score 估计方向相反时，引擎项会放大噪声——论文观察到的时序稳定性下降是否正源于此？若能量化分歧，就能在训练中动态调权。

理论分析：可把梯度写成 $g = \alpha_a g_{\mathrm{aud}} + \alpha_t g_{\mathrm{text}}$，其协方差 $\mathrm{Var}(g) = \alpha_a^2\mathrm{Var}(g_{\mathrm{aud}}) + \alpha_t^2\mathrm{Var}(g_{\mathrm{text}}) + 2\alpha_a\alpha_t\mathrm{Cov}$。若 $\mathrm{Cov}<0$（教师分歧），增大任一 $\alpha$ 都会同时引入偏差-方差此消彼长；最优 $\alpha$ 应与 $\mathrm{Cov}$ 成反比。

连接：与 Decoupled DMD（论文引文 [22]，「CFG 增强为矛、分布匹配为盾」）直接相关；也连接 model merging / teacher ensemble 中的冲突消解文献。

探究方向：训练全程记录两教师 score 的余弦相似度分布，按时间步分桶；以此设计 $\alpha(t) = f(\mathrm{sim}(t))$ 的自适应调度，替代固定 0.1/4.0，验证时序稳定性与文本对齐能否同时不降。

自主科研问题 · Q2

$t_{\mathrm{spot}}$ 的最优位置由什么决定？它与噪声调度、动作频谱是否有一般化关系？

未知与意义：950 这个分界只是经验值（论文表述「typically」）。如果「全局动作在高噪声步定型」是普遍规律，那么 $t_{\mathrm{spot}}$ 应与动作复杂度、视频长度、CFG 离散化存在可推导关系，而非逐任务手调。

理论分析：扩散模型各时间步对应不同空间频率带（低频结构先成形）。若把动作轨迹做频谱分解，$t_{\mathrm{spot}}$ 应对应「动作主频带完成」的时刻；视频越长、动作越快，主频带越宽，$t_{\mathrm{spot}}$ 理应越低。可从频谱截止的角度给出先验估计。

连接：与 AlignHuman 的时间步分段偏好优化、以及「coarse-to-fine 生成」的频率分析工作相连；也呼应 Beyond Monologue 的「说话-倾听时间尺度差异」——两篇都在给模态/行为分配时间尺度。

探究方向：在若干动作复杂度分档的数据上扫 $t_{\mathrm{spot}}$，拟合最优分界与动作频谱带宽的关系曲线，验证是否可用「先估计动作频谱、再定分界」的一般化公式替代手工调参。

自主科研问题 · Q3

免训练多人掩码注意力的边界伪影能否用软路由消除？

未知与意义：硬二值掩码使两个人物的运动在边界处互不可见，递物、握手等交互必然失败；检测抖动还会造成音画错配。软化路由是否能在不训练的前提下改善？

理论分析：硬掩码相当于把注意力核限制在分块对角结构上，其假设是「人物运动互不耦合」。真实多人场景的运动是弱耦合的（接触、遮挡、共同物体），对应注意力矩阵的非对角低秩成分。用距离衰减或检测置信度加权的软掩码，等价于给非对角块一个先验小权重而非零权重。

连接：与 InteractHuman 类布局对齐音频条件工作（论文引文 [39]）、以及图像分割中硬/软掩码的讨论相连。

探究方向：构造含人物接触动作的测试集，比较硬掩码、检测置信度软掩码、以及高斯距离衰减掩码下的交互动作成功率与口型错配率。

自主科研问题 · Q4

HKV 与文本可控性之间是否存在真实的能力张力？

未知与意义：本文 HKV 最低（32.15）但文本对齐最强。论文归因于推理索引 +3 的抑制策略，但未验证。如果张力真实存在，「高表现力」与「听话」可能不可兼得，这对产品选型意义重大。

理论分析：文本条件在双教师目标中被强化，可能使生成分布向「文本可描述的动作」收缩——而手部微动作（HKV 度量的运动丰富度）恰恰是文本提示几乎不描述的自由度。分布收缩牺牲的正是这些未被条件覆盖的维度，类似正则化中「强条件 → 低方差」的取舍。

连接：与条件生成中「条件强度 vs 样本多样性」的经典权衡、以及音频驱动手势生成（CyberHost 的 HKC/HKV 指标体系）相连。

探究方向：对同一模型扫伪末帧索引偏移（+3、+6、+10）与 $\alpha_t$，画出 HKV–文本对齐 Pareto 曲线；若曲线退化为单调取舍，张力成立；若存在平台区，则 +3 只是保守配置。

[示意性实现]
# Twin-Teacher DMD 的 real score（对应论文 Eq.3）+ 动态 CFG 调度
def twin_teacher_real_score(x_tau, tau, c_text, c_audio, eps_audio, eps_text, t_spot=950):
    c_un_text  = negative_prompt_embed      # 负提示条件
    c_un_audio = zero_audio_embed           # 空音频条件（零嵌入）

    # 动态 CFG：高噪声步让文本优先，低噪声步让音频保口型
    alpha_a = 0.1 if tau > t_spot else 4.0
    alpha_t = TEXT_CFG_SCALE                  # 论文未给出具体取值

    base   = eps_audio(x_tau, tau, c_un_text, c_un_audio)
    e_a    = eps_audio(x_tau, tau, c_text, c_audio)   # 音频教师：全条件
    e_t    = eps_text (x_tau, tau, c_text)            # 文本教师：Wan2.2-I2V-14B

    audio_engine = e_a - e_t                  # audio condition engine
    text_engine  = e_t - base                 # text condition engine
    return base + alpha_a * audio_engine + alpha_t * text_engine

def dmd_step(G_theta, z_t, tau):
    x_hat = G_theta(z_t)                      # 学生去噪输出
    x_tau = re_noise(x_hat, tau)              # 重新加噪到噪声级 tau
    s_real  = twin_teacher_real_score(x_tau, tau, ...)
    s_fake  = fake_model(x_tau, tau, ...)     # 学生 EMA 副本的 score
    return -(s_real - s_fake) * grad(G_theta, z_t)   # Eq.1 的梯度方向
[示意性实现]
# 免训练多人对话：按检测掩码给音频交叉注意力「分座位」（对应论文 Fig.6）
def multi_person_audio_cross_attention(video_latent, audio_streams, masks, silent_audio):
    # video_latent: [B, HW*T, D]；audio_streams[k]: 第 k 个人的音频嵌入
    # masks[k]: 检测器给出的二值掩码（该人区域=1，其余=0）
    Q = video_proj(video_latent)              # 查询来自视频 latent
    out = zeros_like(video_latent)
    for k, audio_k in enumerate(audio_streams):
        K_k, V_k = audio_kv(audio_k)          # 键/值来自多路音频嵌入
        attn_k = softmax(Q @ K_k.T / sqrt(d)) @ V_k
        out = out + masks[k] * attn_k         # 该人音频只作用于其掩码区域
    bg = 1.0 - sum(masks)                      # 掩码为 0 的区域
    K_s, V_s = audio_kv(silent_audio)         # 静音音频接管背景区域
    out = out + bg * (softmax(Q @ K_s.T / sqrt(d)) @ V_s)
    return out                                # 全程零训练，支持 3 人以上/多轮对话

# PE 模块：按时长切分文本片段，避免跨段动作重复（Qwen3-VL-32B 之上优化）
def plan_prompt_fragments(user_prompt, audio_duration_s):
    n = min(5, int(audio_duration_s / 3.24) + 1)   # 每 3.24s 一个片段，上限 5
    plan = mllm_agent.decompose(user_prompt, n)        # 语义按时序拆解
    return [plan.assign_to_segment(i) for i in range(n)]
