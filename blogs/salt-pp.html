01 一句话读懂：少步流式生成的两个「上下文错配」，逐一拆掉

少步流式音视频生成同时要求因果建模与步数蒸馏，但标准训练配方撞上两个上下文相关的坑：其一，teacher forcing 把「干净历史」配「噪声目标」，只通过速度预测间接监督预测性的上下文表示；其二，在因果 DMD（分布匹配蒸馏）里用双向 score 模型，导致生成上下文与评分上下文不匹配。Salt++ 用两阶段后训练逐一拆掉它们：Causal Self-Flow（CSF） + context-aligned 自回归 DMD。

深度洞察

「上下文错配」是少步流式生成被低估的敌人

大家习惯把少步生成的失败归咎于「步数不够」。Salt++ 指出真正的病灶在上下文不一致：训练时的上下文分布 ≠ 推理时的上下文分布，于是学生在「没见过的上下文」里乱猜。这与 LeapTalk 讲的暴露偏差同源，但 Salt++ 把它拆成了两处具体错配并分别修复——这种「先定位错配在哪，再对症修」的路径，比一味加参数更有效。

03 阶段一：Causal Self-Flow（CSF）

CSF 的巧妙在于利用上下文信息不对称：保持噪声目标固定，改变历史，让学生用一个「噪声混合历史」去对齐中间表示。这样，上下文表示不再被间接监督，而是被直接拉向正确。

核心操作
固定噪声目标、变化历史 → 迫使模型显式建模「历史如何影响预测」。相对 teacher forcing 的「只看真值历史」，CSF 让学生见过被扰动的历史。
noise-mixed-history
把历史与噪声混合后作为条件，学生对齐中间表示。这直接对抗「干净历史/噪声目标」的错配。
目标
让预测性上下文表示被直接监督，而非经由 velocity 间接学。上下文表示质量是少步生成的关键瓶颈。
性质
属于后训练（post-training），在已有模型上做。成本低，且与「从头训」解耦——可叠加在任何教师上。

深度洞察

「固定一个、扰动一个」是逼出因果依赖的经典手段

要让模型显式依赖某个因素，最直接的办法就是固定其他、只动这一个，看输出变化。CSF 对「历史」做的正是这件事。这与因果推断里的「干预」思想一致——不是被动观察历史与目标的配对，而是主动干预历史、观测反应。把因果思想引入蒸馏，是 Salt++ 的方法论亮点。

04 阶段二：context-aligned 自回归 DMD

DMD（分布匹配蒸馏）用一个 score 模型来评判生成质量。问题在于：学生是因果的，而 score 模型通常是双向的——两者看「上下文」的方式不同，于是蒸馏目标本身错位。Salt++ 的第二阶段把 score 模型改成上下文对齐的自回归形式，让评分时的上下文与生成时一致。

05 关键公式（示意性形式化）

Eq.1 · CSF 的不对称扰动目标（示意）
$$ \mathcal{L}_{\text{CSF}}=\mathbb{E}\Big\| \phi\big(x_{\text{target}}^{\text{noisy}},\, h^{\text{mix}}\big)-\phi\big(x_{\text{target}}^{\text{noisy}},\, h^{\text{clean}}\big)\Big\|^2 $$
直觉：固定噪声目标 x_target，对「噪声混合历史」h_mix 与「干净历史」h_clean 两种条件下的中间表示 φ 做对齐。这样，历史变化引起表示变化这一因果依赖被显式约束。
注意：此式为按 CSF 思路的示意性形式化，原文的精确损失与中间表示定义需查原文式。
Eq.2 · Context-aligned DMD（示意）
$$ \nabla_\theta \mathcal{L}_{\text{DMD}} \propto \mathbb{E}\big[\,s_{\text{AR}}(x) - s_{\text{AR}}(x_{\text{student}})\,\big]\cdot \nabla_\theta x_{\text{student}} $$
直觉：score 模型 s 改为自回归（AR）形式，使其评分时看到的上下文与因果学生一致；于是「生成分布」与「评分分布」对齐，梯度方向才正确。
来源：「context-aligned autoregressive DMD」的思路；具体形式需查原文。

07 批判评估

批判评估

1. 「两阶段」的顺序与必要性未充分消融

为何必须 CSF 在前、AR-DMD 在后？能否只做其一？若缺少「单独 CSF / 单独 AR-DMD」的消融，就无法判断两阶段是必需还是冗余。

批判评估

2. 指标多但缺人评同步维度

Table 2 列了 VQ/MQ/AQ/IB-AV/AVH/Javis/DeSync，其中 DeSync 是同步指标。但联合生成的「同步感」最终靠人评；若缺人评，「context-aligned 提升同步」这一主张证据不足。

批判评估

3. 后训练依赖教师质量

Salt++ 是后训练，能力上限受教师（如 LTX-2）限制。若教师在长尾场景弱，Salt++ 无法弥补。这决定了它的适用范围：适合「已有强教师」的场景。

批判评估

4. 与 OmniForcing、LeapTalk 的对比需更直接

三者都做「实时/少步联合生成」，但路线不同（蒸馏 / bridge / 后训练）。若只与非实时基线比较，会掩盖真正的技术路线竞争。这是本领域普遍的对比口径问题。

08 自主科研问题

自主科研问题 · Q1

「上下文错配」能否被统一成一个可度量的量？

未知与意义：Salt++ 修了两处错配，但没有给出「错配程度」的度量。若能量化，就能预判训练是否收敛。

理论分析：可把错配建模为两个条件分布的散度：D(P_train(history) || P_infer(history))。用 MMD 或 KL 估计它，即可作为训练监控指标。

连接：LeapTalk 的暴露偏差是同一散度的不同表现；两者可统一到「上下文分布匹配」框架下。

探究方向：在训练过程中监控上下文散度，测它与最终生成质量的相关性。

自主科研问题 · Q2

CSF 的扰动强度该如何调度？

未知与意义：历史被扰动多少（噪声混合比例）是关键：太小则学不到鲁棒性，太大则历史信息丢失。

理论分析：扰动强度应逐步增大（类似课程学习），早期轻扰动学基本依赖，后期重扰动学鲁棒性。可用噪声调度的形式化给出准则。

连接：OmniForcing 的 forcing schedule 是同一类「逐步过渡」；Apollo 的多阶段课程也是。

探究方向：对比固定扰动与递增扰动调度，测长时生成的稳定性。

自主科研问题 · Q3

AR score 模型的评分偏差是否也被对齐了？

未知与意义：把 score 模型改成自回归后，其评分偏好是否变了？若 AR 化引入新偏差，可能让蒸馏偏向某些易评模式。

理论分析：score 模型的梯度方向决定蒸馏目标。AR 化改变其感受野，理论上会改变梯度分布。可比较双向 score 与 AR score 的梯度一致性。

连接：AVC-Reward 从「事件级」重新设计评分，是同一问题（评分是否可靠）的另一条路。

探究方向：在同一批样本上比较双向 score 与 AR score 的打分相关性，量化评分偏移。

09 代码附录

[示意性实现]
# Causal Self-Flow：固定目标、扰动历史（示意，非官方）
def causal_self_flow(student, x_target, h_clean, noise_scale):
    h_mix = (1 - noise_scale) * h_clean + noise_scale * torch.randn_like(h_clean)
    rep_mix   = student.encode(x_target, h_mix)     # 噪声混合历史条件
    rep_clean = student.encode(x_target, h_clean)   # 干净历史条件（对齐目标）
    return F.mse_loss(rep_mix, rep_clean)          # 直接监督上下文表示
[示意性实现]
# Context-aligned autoregressive DMD（示意）
def ar_dmd_step(student, ar_score, x):
    x_student = student(x)                   # 因果学生生成
    s_fake    = ar_score(x_student, causal=True)  # AR 评分：上下文对齐
    s_real    = ar_score(x, causal=True)
    grad = (s_fake - s_real)                 # 分布匹配梯度
    return grad

深度洞察

Salt++ 的方法论价值：把「调参」变成「修错配」

少步生成难调，通常被当成超参问题（学习率、步数、损失权重）。Salt++ 的做法是先诊断出两个具体的错配，再针对性设计两阶段。这种「先诊断、再开方」的路径，让改进变得可解释、可迁移——而不是又一组调出来的魔法数字。对所有做少步/流式生成的人，「先找上下文错配」应当成为标准动作。
