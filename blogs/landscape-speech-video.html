01 一句话读懂：说话人视频为什么需要「音画同生」

Speech-Video joint generation 是 Audio-Video 谱系在说话人场景上的收窄与加压：画面上的人必须说出台词、口型必须对上音节、声音必须像参考音色、情绪必须与表情一致。级联方案（TTS 先出语音、视频模型再对口型）在「能说话」层面可行，但误差逐级传播、情绪与语义逐级稀释；本页梳理的谱系——UniTalking、JoVA、Unison、OmniVAE、AVTok、NAVA、MOVA、Ovi、LTX-2、UniAVGen、Soundwich——把语音与说话人视频放进同一个生成过程，并一路推进到「人声/音效分轨」的细粒度控制。

先用两条流水线锚定范式差异。串行范式把 Speech 当作 VidGen 的条件；联合范式让 Vid 与 Speech 在同一个生成器里共同去噪：

串行级联（sequential）：

Text→TTS→Speech→VidGen→Video

联合生成（joint）：

Vid + Speech→Joint 联合生成→说话人视频 ⊕ 语音
图 1 · 说话人视频的两种范式。上排：口型同步靠 VidGen 阶段的事后约束；下排：语音与画面在同一生成过程中共同演化，口型同步成为内生约束——这正是本谱系所有工作的出发点。
深度洞察

说话人场景把「同步」从指标升格为产品约束

通用音视频生成里，音画不同步是「观感问题」；说话人视频里，口型对不上音节是「可用性问题」。这解释了为什么本谱系的语音-视频分支（UniTalking、JoVA、Unison、UniAVGen）比通用分支更执着于局部监督：JoVA 加嘴部区域 Flow Matching 损失、UniAVGen 加 Face-Aware Modulation、Unison 做帧级双向注意力。评测侧同样如此：Sync-D、LSE-C、口型分、WER 成为标配——这些指标测的都是「台词是否真的被说出来」，而不只是「音画是否大致像一起的」。

02 联合生成主线 I：双流 MM-DiT × Joint Attention（UniTalking · JoVA）

最直接的联合方式是把音视频 token 拼在一起做联合注意力：同一组注意力权重同时看两路 token，同步在注意力层「免费」涌现。两个代表工作共享这个骨架，但在监督粒度与条件注入上各走一步。

UniTalking：同构双流 + Joint Attention + Flow Matching

方法
面向 speech＋说话人视频联合生成：视频流复用 Wan2.2-5B，音频流采用同构设计；拼接音视频 token 做 Joint Attention，以 Flow Matching 共同生成。支持文本、身份图像与参考音色条件。
Latent 与解码
保留 Wan2.2 视频 VAE 和 MMAudio 音频 VAE 的各自 latent，通过时间 RoPE 对齐；分别解码画面与 Mel 频谱，再经 BigVGAN 输出 44.1kHz 波形。替代方案：把两路压成同一 latent（AVTok 的 Vanilla 试过，效果不好）；同构双流 + 拼接注意力是「共享注意力、不共享 latent」的折中。
训练与前置
先以 TTS 任务预训练音频分支，再交替训练 T2AV、视频到音频、图像条件联合生成及参考音色任务；编码器冻结。前置包括准确台词、口型同步过滤及参考声音数据。
优势与证据
作者在 20 人、50 条提示的盲评中报告音质与同步优于 Ovi；Sync-D 为 8.05，Ovi 为 8.60。消融显示音频预训练对最终音质关键。

JoVA：Joint Self-Attention（含文本）+ 嘴部区域 Flow Matching

方法
基于 Waver-12B，通过音频、视频、文本 token 的 Joint Self-Attention 统一生成与编辑；音频分支复制视频骨干参数初始化。对说话样本加入嘴部区域 Flow Matching 损失，强化口型细节。
Latent 与解码
采用 Wan2.1 视频 VAE 与 MMAudio 音频 VAE，联合去噪后各自解码；图像/视频条件按通道拼接并附二值 mask，参考音频按 token 拼接，时间 RoPE 负责对齐。条件注入对比：UniTalking 的身份图走条件通道，JoVA 走通道拼接 + mask——后者对「图生/视频生」两态更统一。
训练与前置
先训练音频分支 80K 步，再联合训练生成与编辑 100K 步；约 300 万训练样本包含约 100 万说话场景。需要同步过滤、ASR 台词及嘴部关键点定位。
优势与证据
在作者的 JoVABench-Gen 上，JoVA／Ovi 的 LSE-C 为 6.70／6.41，WER 为 0.19／0.23。笔记提示：JoVABench-Gen 可以活用——它是现成的说话人联合生成评测资产。
图 2 · 双流 Joint Attention 架构流。它把「联合注意力如何同时承载生成与同步」具象化：token 拼接后共享注意力权重，同步不再需要额外对齐模块，而局部嘴部监督把约束进一步压到口型细节。
Eq.1 · 拼接式联合注意力下的 Flow Matching 目标（示意性形式化，非论文原式）
$$ \mathcal{L} = \mathbb{E}_{t}\big\| v_\theta\big([z^{V}_{t}; z^{A}_{t}],\, t,\, c \big) - \big([z^{V}_{1}; z^{A}_{1}] - [z^{V}_{0}; z^{A}_{0}]\big) \big\|^{2} \;+\; \lambda \,\mathcal{L}_{\text{mouth}} $$
直觉：两路 latent 拼成一个序列 $[z^V; z^A]$，一个速度场一次性回归两路目标——「联合」体现在共享的 $v_\theta$ 与注意力内部的跨模态交互；$\mathcal{L}_{\text{mouth}}$ 是 JoVA 式的嘴部区域附加监督，把口型细节的权重抬高（$\lambda$ 为示意系数）。UniTalking 无第二项、JoVA 有第二项，二者的差距就是「局部监督值多少」的天然对照。此式为对笔记描述的示意性归纳，不对应论文原式。

跨论文连接：UniTalking 与 JoVA 都选择「音频分支先训、再联合」——UniTalking 用 TTS 任务预训练并以消融证明其关键性，JoVA 用 80K→100K 的两阶段步数表。这与 MOVA/Ovi/UniAVGen（见 05–06 节）的训练次序完全一致，构成全谱系的隐藏共识（详见 09 节深度洞察）。

批判评估

Sync-D 8.05 vs 8.60：优势真实，但对照口径值得追问

UniTalking 的盲评（20 人、50 条提示）报告音质与同步优于 Ovi，Sync-D 8.05 vs 8.60。但 Ovi 是通用音视频联合模型（其对比对象是 JavisDiT、UniVerse-1），并非说话人特化模型——用它作说话人场景的对照，测出的可能是「特化 vs 通用」而非「架构 A vs 架构 B」。另外 20 人×50 提示的规模对 5 分制量表的置信区间并不宽裕。JoVA 的 JoVABench-Gen（LSE-C/WER 口径）是更适合说话人场景的对照资产，笔记也提示它可以活用。

03 联合生成主线 II：人声＋音效的分轨联合（Unison）

前一节的「一条音轨」假设在真实视频里站不住：说话人视频同时含人声与背景音效。Unison 直接研究视频＋speech＋背景音效的三方联合，并给出本谱系中唯一在训练期显式分轨的音频表示设计。

方法
Wan2.2-5B 视频分支与 MMAudio／Zipformer 音频分支通过帧级双向注意力交互；音频内部用 Bi-ACA＋语义条件门控协调人声和音效。
Latent 与解码
音频显式保留 speech／SFX 两路 latent，共享时间索引、在层内交互并分别预测；视频保留自身 latent，生成结果通过对应解码路径还原画面与声音。替代方案：单条混合音轨 + 推理期分离——Unison 把分离前置到表示层，代价是需要分离监督。
训练与前置
用 Mel-Roformer 分离人声／音效并分别施加 Flow Matching 监督；先训练音频，再冻结视频骨干、训练音频与融合模块。Cross-Modal Forcing 从同步噪声逐步过渡到独立噪声，让较清晰模态指导另一模态。
优势与证据
作者消融中，完整模型相对移除音频协调策略，PQ 从 6.12 提升至 6.34；相对移除 Cross-Modal Forcing，失同步指标 DS 从 0.19 降至 0.08。
图 3 · Unison 的分轨联合示意。它把「一条音轨里混着人声和音效」的纠缠问题，拆成两路显式 latent + 帧级交互 + 分离监督三个机制——训练期分轨的代价与收益都写在这张图里。
深度洞察

Cross-Modal Forcing 是「噪声调度」级别的同步机制

多数工作用位置编码（RoPE 族）或注意力结构解决同步，Unison 却把同步做进了扩散噪声过程本身：从同步噪声逐步过渡到独立噪声，让较清晰的模态指导另一模态。其消融（DS 0.19 → 0.08）显示这是它同步能力的最大贡献者。理论上这相当于给两路去噪轨迹加了一个「逐渐放开的手」：早期耦合强、防止漂移，后期独立、允许细节分化。把这一机制与 MOVA 的 Aligned RoPE、JoVA 的嘴部损失叠加，是否还有增益，是 Q3 的直接实验。

深度洞察

Unison 与 Soundwich：同一问题的两种哲学

面对「speech + 音效 + 背景声」，Unison 选择训练期分轨（显式双 latent + 分离监督），Soundwich（07 节）选择推理期分轨（training-free 多轨迹 + 实体路由）。前者上限更高、前置更重（Mel-Roformer 分离数据）；后者零训练、但受限于基座可分解性与「可见声源」假设。两者的胜负手在画外声源与声源数量动态变化的场景——目前无对照数据，见 Q4。

04 表示层路线：统一/对齐表示（OmniVAE · AVTok）

如果 latent 本身就对齐、可重建、语义一致，下游的说话人生成器就只需学「口型与语音的联合分布」。这条路线对「共享到什么程度」给出了两个方向相反的答案。

OmniVAE · 方法
在表示层学习音视频对齐：保留音频和视频各自的 VAE，在 latent 上加入片段级双向对比学习，并从预训练语义编码器蒸馏模态知识，让下游生成器获得更容易学习的表示。
OmniVAE · Latent 与解码
两路保留各自可重建的 latent，通过共享语义坐标建立细粒度对应；下游 DiT 生成音视频 latent，再由各自 decoder 还原。替代方案：共享联合隐变量——AVTok 的 Vanilla 实验表明效果不好。
OmniVAE · 训练与证据
需要同步配对片段、重建目标和冻结语义教师；先训练/适配 VAE 再验证下游。证据：latent 同步探测 + 下游 T2AV，报告语义蒸馏与片段级对齐的互补收益。
AVTok · 方法
统一音视频 tokenizer：视频与音频频谱分别切块，经可学习查询压缩为一维离散 token；两路共享编解码器主干和码本，保留各自的查询、归一化层和 token 序列；生成阶段用自回归模型预测 token。
AVTok · Latent 与解码
模态各自的 token 序列，共享主干与码本；视频 token 还原画面，音频 token 还原频谱并经声码器输出波形。笔记旁注：Vanilla 尝试过共享 latent、共享参数，效果不好；双流版本重建更好。
AVTok · 训练与证据
需要成对音视频重建数据；VFAL 分阶段训练：先视频、再音频、最后微调解码器，加特征对齐与自回归预测目标。证据：双流重建更好，验证音到视频、视频到音频和类别条件联合生成；指定台词与复杂声景为后续验证项。
图 4 · 统一表示 vs 双流表示的范式对比。它把「tokenizer、codebook 或 VAE latent 应共享和对齐到什么程度」这一研究问题具象化为三档设计，AVTok 的 Vanilla 失败钉住最左端。

批判视角：表示层路线目前的证据都止步于「重建更好 / 下游更易学」，尚无指定台词（scripted speech）与复杂声景下的说话人生成结果——而这两项恰是说话人场景的核心需求。对说话人视频而言，OmniVAE 的「共享语义坐标」若能对齐到音节/口型级别而非片段级，才真正接得上 JoVA 的嘴部监督逻辑。

05 对齐-融合与双塔路线（NAVA · MOVA · Ovi）

不动 latent、只改网络内部分工的三个代表：NAVA 把对齐与融合拆成前后两段；MOVA 用 Bridge + Aligned RoPE 连接双塔；Ovi 用逐层双向交互的对称双 DiT。

NAVA · 方法
Align-then-Fuse MMDiT：前部层建立音视频对应，后部层共享参数联合去噪；文本与参考音色作外部上下文，Timbre-in-Context Conditioning 把音色绑定到具体台词片段。
NAVA · Latent / 训练 / 证据
输入音视频 latent 经模态感知对齐进入共享融合层，输出走各自 VAE 解码。复用 Wan 视频骨干与视频 VAE、LTX 音频 VAE；渐进混合音频单模态与配对音视频训练 + 音色条件 dropout。证据：Verse-Bench、Seed-TTS 与人评报告同步、视觉质量与音色控制收益。
MOVA · 方法与 Latent
双塔：Wan2.2 视频 DiT + 1.3B 音频 DiT 文本条件下联合去噪，双向 Bridge Cross-Attention 交换特征；Aligned RoPE 把两路位置映射到统一时间尺度。各自 latent、各自 VAE 解码，输出视频及语音、音效和音乐。笔记旁注：audio 的 latent 要远远稠密 video 的 latent。
MOVA · 训练与证据
先建立音频塔生成能力，再联合训练双塔与 Bridge；Bridge 与骨干差异学习率、音视频可分别调节的噪声调度。证据：语音、音画对齐与人评 + 推理控制消融；冻结双塔暖启动较早达到平台，最终采用联合更新（第 4.4 节）。
Ovi · 方法与 Latent
对称双 DiT：视频分支 Wan2.2-5B 初始化、音频分支匹配架构，每层双向 Cross-Attention 交换信息，缩放 RoPE 对齐时间。分别编码、联合去噪；音频用 MMAudio VAE → 频谱 → BigVGAN。
Ovi · 训练与证据
先预训练音频塔并补音效数据，再训融合；融合阶段冻结 FFN，更新单模态与跨模态注意力。证据：Verse-Bench 人评相对 JavisDiT、UniVerse-1 的质量与同步偏好优势（联合模型间比较）。
图 5 · S-A 对齐示意：把「同步」具象化为三个层次——表示层（latent 对应）、结构层（时间位置编码）、内容层（口型/面部局部约束）。各工作分别占一到两层，从无统一消融。
深度洞察

三种交互密度对应三种成本曲线

MOVA 的 Bridge（模块级交互）、Ovi 的逐层 Cross-Attention（每层交互）、NAVA 的前后分工（阶段级交互）构成一条交互密度谱系。密度越高，同步与细节协调的上限越高，但每步去噪的算力开销与训练耦合风险也越大。MOVA 的「冻结暖启动很快到平台、最终联合更新」提示：交互模块与骨干是协同塑形的，低密度交互更需要联合更新来打通接口。选择哪种密度，本质是在「训练稳定性预算」与「同步上限」之间定价。

批判评估

「联合模型之间比较」的证据闭环缺一角

Ovi 的优势证据是相对 JavisDiT、UniVerse-1 的人评偏好——笔记特别注明「这是联合模型间的比较」。对说话人场景的落地决策而言，真正需要的对照是级联强基线（TTS + 专用口型模型），而本节三个工作都没有报告这一对照。旁证是 06 节 UniAVGen 的表 1：联合模型在情绪一致性上大胜级联基线，却在音频 PQ（7.00 vs 8.15）和口型分（5.95 vs 6.34）上落后。在补齐级联对照之前，「联合优于级联」在说话人场景仍是未证实命题。

06 非对称双流与人脸/情感控制（LTX-2 · UniAVGen）

两个工作把双流路线推向「非对称」与「局部控制」：LTX-2 用 14B/5B 的非对称容量 + 模态感知 CFG；UniAVGen 用非对称时间对齐交互 + Face-Aware Modulation 聚焦人脸，并给出本谱系唯一一组「联合 vs 级联」的分项数字。

LTX-2 · 方法
非对称双流 Transformer，原始报告中视频流 14B、音频流 5B；双向音视频注意力、时间位置编码与共享噪声条件联合生成；模态感知 CFG 分别控制文本遵循与声画关联。
LTX-2 · Latent / 训练 / 证据
各自 VAE latent，双流交互共同演化，分别解码输出画面和含 speech、环境声及拟音（Foley）的音轨。训练数据需同步视频、音轨和完整 caption（台词、说话人、语言、口音、环境声音）。证据：音视频人评 + 跨模态 guidance 分析——增强跨模态 guidance 可改善同步与语义一致性。
UniAVGen · 方法
音视频双分支 + 非对称时间对齐交互：音频线索指导口型和动作，视觉线索帮助声音匹配表情与身份；Face-Aware Modulation 聚焦人脸；模态感知 CFG 控制跨模态关联。支持参考图像、指定台词和可选参考声音。
UniAVGen · Latent / 训练 / 证据
视频用 Wan VAE latent；音频用 Mel 频谱 + 声码器。先训音频分支，再在真实配对音视频上联合更新，随后多任务训练：联合生成、续写、配音、音频驱动视频。证据（表 1，vs F5-TTS＋OmniAvatar）：情绪一致性 0.573／0.349，音频 PQ 7.00／8.15，口型分 5.95／6.34；情绪评分由多模态模型给出，笔记认为值得补充人类盲评。

深度解读：UniAVGen 的三个数字构成一张「联合生成能力剖面图」：情绪一致性 0.573 vs 0.349 的大幅领先说明联合生成真正赚到的是跨模态语义/情感协调；而 PQ 7.00 vs 8.15、口型 5.95 vs 6.34 的落后说明逐项保真（纯音质、纯口型精度）仍是级联方案的领地。换言之，联合生成目前买到的是「一致性」，付出的是「单项保真」。多任务训练（续写、配音、音频驱动视频）则暗示另一条产品化路径：与其在单指标上追平级联，不如占住级联做不到的双向可驱动能力。

批判评估

非对称容量（14B/5B）是对「音频 latent 稠密」的正确回应吗？

MOVA 的笔记旁注说「audio 的 latent 要远远稠密 video 的 latent」，而 LTX-2 却给视频侧更大参数量（14B vs 5B）。两者并不矛盾但值得追问：稠密的是信息量，参数分配还取决于先验难度——视频先验（Wan 系骨干）已经很强，音频先验弱，按「补弱者」逻辑反而应给音频侧更多容量。LTX-2 的分配逻辑与 MOVA 的差异学习率、Ovi 的「匹配架构」共同暴露一个未被显式研究的问题：双流的容量/学习率/噪声调度该如何按模态不对称性联合定价？（见 Q2）。

07 多声源分轨控制（Soundwich）

说话人视频的真实声景是「人声 + 音效 + 背景声」三轨并存，而前述所有工作都把它们压成一条音轨。Soundwich 的答案：在冻结的原生音视频模型上扩展多条音频生成轨迹，training-free，各轨独立可编辑。

方法
冻结原生音视频模型，扩展多条音频生成轨迹、保留同一视频轨迹；通过共享场景信息、逐声源 guidance、时间控制与实体注意力路由，输出分别可编辑的人声、音效和背景声。
Latent 与解码
多个声源各有音频 latent，视觉端共享视频 latent；音轨分别解码后混音，支持静音、替换、重排和单独调节。对照：Unison 在训练期显式建模 speech/SFX 双 latent（03 节）——训练期分轨 vs 推理期分轨。
训练与前置
training-free 推理改造，复用已有联合生成器；前置包括源级声音条件、可选时间窗口，以及可见声源的分割/实体对应。
优势与证据
论文实验与人评报告时间控制、音源分离和自然度的改善，并通过组件消融分析场景广播与实体路由。
图 6 · 多声源分轨示意。它把「speech、背景声与音效如何同步生成并独立编辑」具象化为轨迹结构：一条共享视频轨迹 + 按声源分轨的音频轨迹，编辑自由度从「整条音轨」细化到「单个声源」。
深度洞察

training-free 分轨改写了「联合」的验收标准

Soundwich 证明：只要基座联合生成器的多声源信息是可路由的，分轨编辑可以在推理期近乎免费获得。这把评价重心从「模型有没有分轨能力」转向「基座的声源纠缠度」——一个纠缠严重的基座，实体路由再精巧也分不干净。反过来看，Unison 式训练期分轨的价值被重新聚焦为两点：提升生成质量上限（显式监督让各轨各自更好）与覆盖不可见声源（不依赖实体锚点）。这层重估是本页把 Soundwich 与 Unison 并置的原因。

09 深度洞察 & 批判评估

深度洞察

「先音频后联合」是全谱系的隐藏共识，其根源是预训练不对称

UniTalking 用 TTS 预训练音频分支（消融证明对音质关键）、JoVA 80K 步音频分支再 100K 联合、MOVA「先建立音频塔」、Ovi「先预训练音频塔」、UniAVGen「先训练音频分支」——五个工作同一训练次序。根源是结构性的：视频侧可直接复用 Wan2.2/Wan2.1 等强骨干（UniTalking、JoVA、MOVA、Ovi、UniAVGen 全部如此），音频侧只有 MMAudio VAE 级别的复用，生成骨干基本要自己建。当前「联合生成」的实态是强视频塔 + 冷启动音频塔 + 中途焊接的交互层；谁做出音频侧的「Wan 级」预训练基座，谁就改写整条路线的成本结构。

深度洞察

同步监督三级下沉：位置 → 结构 → 器官

把本谱系的同步机制排成一条下沉链：位置级（时间 RoPE/缩放 RoPE/Aligned RoPE，解决时间戳映射）→ 结构级（Joint Attention、帧级双向注意力、Bridge，解决跨模态信息流）→ 器官级（JoVA 嘴部区域 Flow Matching、UniAVGen Face-Aware Modulation，解决「嘴型对音节」）。越往下越贴近说话人场景的真实验收标准，但标注成本越高（嘴部关键点、人脸分割）。JoVA 的组合（共享注意力 + 局部嘴部监督）代表当前最激进的下沉方案，其 LSE-C 6.70 与 WER 0.19 可视为这条设计路线的强证据。

批判评估

三处证据裂缝：对照口径、指标来源、规模

对照口径：UniTalking 对比的 Ovi 是通用音视频模型，Ovi 对比的 JavisDiT/UniVerse-1 是联合模型——真正需要的「级联强基线」对照只在 UniAVGen 表 1 出现，且结果是互有胜负（情绪赢、PQ/口型输）。指标来源：UniAVGen 情绪一致性由多模态模型打分，笔记原话「值得补充人类盲评」。规模：UniTalking 盲评 20 人 × 50 提示；JoVA 的 300 万样本/100 万说话场景是训练规模而非评测规模。此外 benchmark 碎片化（JoVABench-Gen、Verse-Bench、Seed-TTS 各自为政）使跨工作排序只能靠人评口径间接推断。

批判评估

训练数据的前置成本被架构创新掩盖

本谱系每个工作的「训练与前置」栏都列着一串昂贵准备：口型同步过滤（UniTalking）、ASR 台词 + 嘴部关键点（JoVA）、Mel-Roformer 分离（Unison）、同步过滤 + 含台词声景描述（Ovi）、完整 caption 含说话人/语言/口音（LTX-2）。架构上的联合注意力是「免费」的，但让联合训练真正有效的数据清洗才是成本大头。评估路线优劣时，应把「前置成本」与「模型效果」放在同一张表里——目前笔记中的证据只覆盖后者。

10 自主科研问题

自主科研问题 · Q1

局部口型监督的收益边界：需要多细的标注，收益何时饱和？

未知与意义：JoVA 用嘴部区域 Flow Matching 损失强化口型，UniAVGen 用 Face-Aware Modulation 聚焦人脸，但两者都未报告「监督粒度-收益」曲线。若粗粒度（人脸框）已获大部分收益，昂贵的嘴部关键点标注可以省掉。

理论分析：全局同步指标对「音节→口型」只有间接约束（见 09 节三级下沉链）；局部损失把梯度直接压到嘴部区域，等价于提高该区域在速度场回归中的权重。可预期收益随标注粒度递增但边际递减，饱和点对应口型可辨识度的上限。

连接：JoVA 的 LSE-C 6.70／WER 0.19（vs Ovi 6.41／0.23）、UniAVGen 口型分 5.95 vs 6.34（输给级联）、UniTalking 的口型同步过滤前置。

探究方向：同一双流基座上扫四档监督（无 / 人脸框 / 嘴部框 / 嘴部关键点），用音节级口型指标 + 人评分档评测，定位饱和点与标注成本的平衡。

自主科研问题 · Q2

模态不对称性的联合定价：容量、学习率、噪声调度怎么配？

未知与意义：笔记旁注「audio 的 latent 要远远稠密 video 的 latent」，而各工作的应对互相矛盾：LTX-2 给视频侧更大参数（14B/5B）、MOVA 用差异学习率与可分别调节的噪声调度、Ovi 用「匹配架构」+ 冻结 FFN。没有工作系统扫过这三个旋钮的联合配置。

理论分析：模态不对称有两面——信息密度（音频稠密）与先验强度（视频骨干强）。参数应补「先验弱」的模态，调度应迁就「信息密」的模态，二者方向不同，这解释了各工作配置的分歧。可用梯度噪声尺度/收敛速率不对称性来形式化。

连接：MOVA 的联合更新 vs 冻结暖启动消融（第 4.4 节）、LTX-2 的非对称双流、Ovi 的 FFN 冻结策略、UniTalking 的音频预训练消融。

探究方向：在统一基座上做容量比 × 学习率比 × 噪声调度比的三因素实验，监控两塔的梯度范数与时序同步指标，找出「联合更新何时必须解冻」的相变点。

自主科研问题 · Q3

同步机制的可叠加性：RoPE、Cross-Modal Forcing、局部损失是互补还是冗余？

未知与意义：Unison 的 Cross-Modal Forcing（DS 0.19→0.08）与 MOVA 的 Aligned RoPE、JoVA 的嘴部损失各自被单独消融证明有效，但三者叠加是否仍有增益未知——若冗余，可以砍掉最贵的一个。

理论分析：三者作用层面不同：RoPE 管时间戳映射（防漂移），Forcing 管噪声过程耦合（防分叉），局部损失管内容对应（防口型错配）。理论上互补，但都消耗模型容量去「纠同步」，可能互相挤占。

连接：Unison 的 DS 消融、MOVA 的推理控制消融、JoVA 的嘴部监督组合、09 节三级下沉链。

探究方向：2×2×2 因子消融，分层评测（秒级漂移/音节口型/语义一致），识别各机制的专属作用层与重叠区。

自主科研问题 · Q4

多声源分轨：画外声源与动态声源数下，两条分轨路线谁更鲁棒？

未知与意义：Soundwich 的实体注意力路由以「可见声源的分割/实体对应」为前置，Unison 的训练期分轨依赖 Mel-Roformer 分离监督。画外音、环境声、声源数量变化是两者的共同压力测试点，目前无对照数据。

理论分析：推理期路由假设声源信息在基座中线性可分解且有视觉锚点；训练期分轨把分解写进表示，但受限于分离监督的质量。画外声源打破锚点假设，动态声源数打破「固定轨迹数」的结构假设。

连接：Soundwich 的场景广播与实体路由消融、Unison 的 Bi-ACA＋语义条件门控、AVTok 的模态信息平衡检查。

探究方向：构造含画外音/可变声源数的说话人测试集，对比两路线的分离质量、编辑一致性、同步指标与「路由失败时的降级行为」。

以下两段不是任何论文的官方实现，仅把本页机制（拼接式联合注意力、训练期分轨 + Cross-Modal Forcing）写成可读的示意流程。

# UniTalking/JoVA 式拼接 Joint Attention 联合去噪（示意）
def joint_attention_denoise(z_v, z_a, conds, steps):
    # conds: 文本/台词 · 身份图像（通道拼接 + 二值 mask）· 参考音色
    for t in timesteps(steps):
        x = concat_tokens(z_v, z_a)          # 音视频 token 拼接为一个序列
        x = x + time_rope(t)                 # 时间 RoPE 对齐两路位置
        v = joint_mm_dit(x, t, conds)        # 共享注意力权重（Joint Attention）
        v_v, v_a = split(v)
        z_v = euler_step(z_v, v_v, t)
        z_a = euler_step(z_a, v_a, t)
        # JoVA 追加：嘴部区域 Flow Matching 损失（训练时）
        loss_mouth = flow_matching(z_a_pred, z_a_gt, mask=mouth_region(conds))
    video = wan_vae.decode(z_v)              # 画面
    mel   = mmaudio_vae.decode(z_a)          # Mel 频谱
    return video, bigvgan(mel)               # BigVGAN → 44.1kHz 波形

# Unison 式训练期分轨 + Cross-Modal Forcing（示意）
def unison_train_step(video, mix_audio, t):
    speech_tgt, sfx_tgt = mel_roformer_separate(mix_audio)  # 分离监督
    z_v = wan_vae.encode(video)
    z_sp, z_sfx = encode(mix_audio)          # speech / SFX 两路 latent，共享时间索引
    # Cross-Modal Forcing：同步噪声 → 独立噪声（按训练进度插值）
    noise = lerp(synced_noise, independent_noise, progress(t))
    # 音频内部：Bi-ACA + 语义条件门控协调人声与音效
    z_sp, z_sfx = bi_aca(z_sp, z_sfx, gate=semantic_cond)
    # 帧级双向注意力：视频分支（冻结）与音频分支交互
    feats_v = frozen_video_branch(z_v, t, attend_to=[z_sp, z_sfx])
    feats_a = audio_branch([z_sp, z_sfx], t, attend_to=feats_v)
    return flow_matching(feats_v, z_v) \
         + flow_matching(feats_a.speech, speech_tgt) \
         + flow_matching(feats_a.sfx, sfx_tgt)             # 分别施加 FM 监督
