01 一句话读懂：给 LLM 装上一张会听会说的脸

EmbodiedHead 回答的是一个工程化三难问题：一个真正能上线的头部具身数字人（Head-Embodied LLM Avatar），必须同时做到实时生成、听-说统一行为、高渲染画质——而这三者在既有技术路线里互相牵制。论文的解法是把首个用于该任务的 Rectified-Flow Diffusion Transformer（DiT）与可微渲染器耦合，用 4 步采样跑出高保真动作；再用单流音频接口 + 逐帧听-说状态（LS-state）条件加一个 Streaming Audio Scheduler，去掉双流方法对「对方同窗反应」的 look-ahead 依赖，实现无缝轮替；最后用两阶段训练（系数空间预训练 + 图像域联合精调）弥合「动作级监督」与「用户真正看到的渲染质量」之间的鸿沟。

论文的核心叙事可以压缩成一句话：过去的 3D talking-head 方法在系数空间（FLAME 参数）里训练和评测，报出的速度与精度并不等于用户屏幕上看到的东西；而过去的听-说统一方法用双流音频训练，在真实的 user–LLM 对话里根本拿不到同窗的对方反应音频。EmbodiedHead 把这两个「评价口径/接口口径」的问题一起修掉，并把速度压到单卡 RTX 3090 上全链路 59 FPS（仅动作系数生成模块超过 900 FPS，论文表述）。

深度洞察

「具身社会在场」不只是画质问题，而是交互因果性问题

论文开篇引用 Embodied Social Presence（ESP）理论：具身表征是人体验共在感（co-presence）的焦点，更丰富的具身线索会强化临场感与参与度。但 EmbodiedHead 真正的贡献在于把「临场感」拆成了一个因果性约束：用户–LLM 对话是严格因果流，任何需要「未来窗口内对方反应」的条件在推理时都不存在。于是「听-说统一」不是一个生成质量问题，而是一个条件可得性问题——这正是单流接口 + LS-state 的设计动机，也解释了为什么双流方法在实际部署中会「退化为轮流的单音频驱动」（论文表述）。

02 范式定位：为什么放弃双流音频

听-说统一生成经历了从「单听者建模」（Learning to Listen）到多轮流式框架的演化：DualTalk 把它扩展到多轮双人对话，但整段音频离线一次生成，无法流式部署；TIMAR 引入轮次级因果建模，却要吃对方视觉流作为输入，实时场景采集成本高；INFP 与 UniLS 在双流音频设定下继续改进自然度与连续性。EmbodiedHead 对这条线的批判相当直接：所有双流方法共享一个结构性缺陷——生成当前窗口需要同一时间跨度内对方的反应音频/视觉，而真实 user–LLM 聊天里这不可得；实践中这些方法会退化成交替单音频驱动，倾听阶段的模式推断不可靠。

图 1 · 范式对比：把「对方同窗反应」这个推理时不可得的条件（上）替换为「音频来源决定的逐帧 LS-state」（下），是 EmbodiedHead 实现因果流式听-说统一的关键一步。

另一个被 EmbodiedHead 点名的问题是 MANGO：它意识到图像域监督的价值，但建立在 DDPM 上，需要多步采样才能出可靠结果——DDPM 的单步估计误差大，图像域损失无法锚定在与真实推理行为一致的输出上，这为后文 Rectified Flow 的「单步端点估计」埋下伏笔（第 04 章）。

03 系统分解：Rectified-Flow DiT × 可微渲染器

给定音频片段 a，模型要在长度 T 帧的流式窗口内生成时序连贯的 3D 动作序列 x₁ ∈ ℝ^{T×D}。脸部几何用 FLAME 参数化：逐帧表情 e^τ ∈ ℝ¹⁰⁰ 与姿态 p^τ，共享身份形状 s ∈ ℝ³⁰⁰；附录给出的完整动作向量为 115 维（100 个表情系数 + 下颌姿态、眼球姿态、全局旋转、全局平移），预测窗口 100 帧、帧率 25 FPS（约 4 秒）。

图 2 · 架构流：把「调度器 → 音频编码 → 多条件 DiT → 少步采样 → 可微渲染」这条链画出来，才能看清为什么图像域能监督到「真正被采样的端点」。
Latent 与解码
不做隐空间压缩：DiT 直接在 FLAME 系数空间预测 115 维速度场，末端由 GAGAvatar 可微渲染器把 FLAME 网格解码为图像。渲染器显式建模口腔内部（牙齿、舌头），对说话外观至关重要。替代方案：NeRF/3DGS 逐人重建路线外观细节更好，但场景近乎静态、需昂贵的逐人重建，不适合通用 LLM 部署。
训练与前置
数据：自建 11,372 条样本 / 27.2 小时（TFHP 14.7h + TalkVid & VFHQ 7.8h + RealTalk 3.9h 专攻倾听行为），FLAME 伪真值由 GAGAvatar 跟踪管线提取；测试集为 100 条说话 + 50 条倾听片段。音频前置为冻结的 mHuBERT-147（多语言），逐层 softmax 加权融合。替代方案：直接在跟踪伪真值上端到端训练会被跟踪噪声反噬，故拆成两阶段（见第 07 章）。
流式接口
单音频流 + 逐帧 LS-state q ∈ {−1,+1}（+1 说 / −1 听）。训练期用 TalkNet-ASD 产出帧级说话置信度、短时平滑后二值化；推理期按音频来源标注（LLM 来源 → +1，环境/麦克风 → −1）。替代方案：让模型自己从音频推断模式——消融显示会把微弱/远处语音误判为倾听，并出现无意义张嘴。
采样与推理
Rectified Flow 直路径支持可靠单步端点估计，默认 4 步 Euler 积分，运动幅度引导设为 0.3（论文表述）。全链路 59 FPS（RTX 3090），仅动作系数模块 >900 FPS。
双音频源→ Scheduler（窗口 + q）→ mHuBERT 音频 token→ RF-DiT ×8→ FLAME x̂₁→ GAGAvatar 渲染

04 关键公式：直路径流匹配如何撑起少步生成与图像域监督

Rectified Flow 的价值不只是「少步」。它把噪声 x₀ ~ 𝒩(0, I) 与数据 x₁ 之间定义为直线插值路径，目标速度恒为 x₁ − x₀——这个「位移场」性质让单步 Euler 估计就落在真实端点附近，从而 Stage II 的图像损失可以直接监督推理时真正会被渲染的那个输出。这是 EmbodiedHead 与 MANGO（DDPM 单步误差大、图像监督悬空）的本质差异。

Eq.2–3 · Rectified Flow 路径与 Flow Matching 目标
$$ \mathbf{x}_t = \mathbf{x}_0 + t\,(\mathbf{x}_1 - \mathbf{x}_0),\qquad t\sim\mathcal{U}[0,1] $$
$$ \mathcal{L}_{\mathrm{FM}} = \mathbb{E}\Big[\big\|\mathbf{v}_\theta(\mathbf{x}_t, t, \mathbf{c}) - (\mathbf{x}_1 - \mathbf{x}_0)\big\|_2^2\Big] $$
直觉：x₀ 是高斯噪声、x₁ 是真实 FLAME 动作序列；路径是直线，所以目标速度 u_t = dx_t/dt = x₁ − x₀ 是常向量。网络学的是「从任意 t 出发往数据端走多远」的位移场，而不是 DDPM 那种需要多步去噪的分数场。条件集合 c = (a, s, x_ref, x_hist, q, m) 分别是音频、身份形状、参考帧、历史动作、LS-state 与运动幅度。
Eq.5 · 状态条件 FiLM 调制（音频进 cross-attention 之前）
$$ \hat{\mathbf{A}}^{\tau} = \mathbf{A}^{\tau} \odot \big(1 + \boldsymbol{\alpha}(q^{\tau})\big) + \boldsymbol{\beta}(q^{\tau}) $$
直觉：同一段声学特征在「我在说」和「我在听」两种模式下应有完全不同的解释方式——FiLM 让逐帧状态 q^τ ∈ {−1,+1} 对音频特征做仿射重标定（缩放 1+α、偏移 β）。[α(q^τ), β(q^τ)] ∈ ℝ^{2D} 由零初始化的轻量 MLP 产出（附录：隐层 112 维、输出权重零初始化，训练从恒等映射起步）；每个 DiT 块有独立调制参数，块内跨时间步共享。
Eq.6 · Stage I 系数空间分组加权目标
$$ \mathcal{L}_{\mathrm{I}} = \sum_{k\in\mathcal{K}} \lambda_k \big\| \mathbf{v}_\theta^{(k)} - (\mathbf{x}_1^{(k)} - \mathbf{x}_0^{(k)}) \big\|_2^2 + \lambda_{\mathrm{smooth}}\,\mathcal{L}_{\mathrm{smooth}}^{\mathrm{pose}} $$
直觉：动作向量被拆成 5 个参数组 𝒦 = {表情, 下颌, 眼球, 旋转, 平移} 分组计损。附录给出系数：λ_expr = 0.6，λ_jaw = λ_eye = λ_rot = λ_trans = 0.1，λ_smooth = 0.1；位姿平滑项 ℒ_smooth^pose = Σ_τ ‖p^{τ+1} − p^τ‖²₂ 只作用于旋转与平移维度，压制剪辑与跟踪抖动，同时刻意排除表情与下颌以免过度平滑唇部发音。
Eq.7–8 · 单步端点估计与 Stage II 图像域联合目标
$$ \hat{\mathbf{x}}_1 \approx \mathbf{x}_t + (1-t)\,\mathbf{v}_\theta(\mathbf{x}_t, t, \mathbf{c}) $$
$$ \mathcal{L}_{\mathrm{II}} = \lambda_{\mathrm{coef}}\,\mathcal{L}_{\mathrm{I}} + \lambda_{\mathrm{img}}\Big(\lambda_{1}\|\hat{\mathbf{I}}-\mathbf{I}\|_{1} + \lambda_{p}\|\psi(\hat{\mathbf{I}})-\psi(\mathbf{I})\|_{2}^{2}\Big) $$
直觉：因为目标速度恒定，设 t=0 的单步推断就「恰好等于」被渲染的端点，于是图像损失监督的正是推理输出本身。Î = R(x̂₁, s) 为 GAGAvatar 渲染，ψ(·) 是冻结的 AlexNet-LPIPS 特征。附录系数：λ_coef = 0.2、λ₁ = 0.2、λ_p = 0.2，渲染分辨率 256×256，渲染器学习率为基础值 ×0.5；外层 λ_img 的具体数值论文未给出（论文表述）。
Eq.14–15 · 多样性指标 SID（附录 B.2 核对）
$$ \mathrm{SID}_k = -\sum_{c=1}^{K} p_c \log_2(p_c + \epsilon),\qquad \epsilon = 10^{-8} $$
$$ \mathrm{SID} = \frac{1}{3}\big(\mathrm{SID}_{\mathrm{jaw}} + \mathrm{SID}_{\mathrm{exp50}} + \mathrm{SID}_{\mathrm{rot}}\big) $$
直觉：对同一音频生成的多样本，在真值特征分布上拟合 K-Means，用聚类分配直方图的香农熵度量多样性；最终 SID 是下颌、前 50 个主表情维、旋转三个语义组的均值。配套指标：LVE（唇部顶点最大 L2 误差均值）、FDD（上脸相对运动时序标准差之差）、MOD（上下唇关键点 62/66 距离的平均绝对误差）、BA（高斯核 σ=0.1s 的双向节拍对齐）。

05 条件注入三通路与 History Context Packing

DiT 的条件不是一把梭哈进 cross-attention，而是走了三条互补通路，各有分工：输入端把 LS-state 作为额外通道拼进每一帧特征（提供显式模式指示并形成模式一致的时序上下文）；音频 cross-attention 前用 FiLM 做状态调制（把模式信号贯穿网络深度）；AdaLN 注入全局条件（时间步、参考、全局音频、运动幅度）。这种「表层通道 + 深层调制 + 全局门控」的分层设计，本质上是在对抗一个数据侧的退化解：如果模式信号太弱，模型会把倾听误判为说话、在倾听时幻觉性张嘴。

图 3 · HCP 与条件通路：把「指数增长感受野的历史压缩」与「模式信号的三层注入」并排，可见该架构在 120 token 的短序列里塞进了 4 秒当前窗口 + 3 秒历史（75 帧 @25FPS）。
深度洞察

HCP 是对「生成式视频模型漂移」问题的移植式解法

History Context Packing 灵感来自下一帧预测视频扩散模型的 frame context packing（论文引文 [44]，用于防漂移）。在 talking-head 任务里它解决的是另一组矛盾：流式窗口需要长历史来保持身份/姿态连续，但 self-attention 复杂度随序列长度平方增长。指数增长跨度（5/10/20/40 帧）+ 每组固定 5 token，本质是一种对数尺度的记忆分配——近处动作细节高分辨率保留、远处只留趋势，与语音编码里多尺度特征金字塔、甚至神经科学里工作记忆的粗细粒度分层异曲同工。值得注意的是 cross-attention 刻意只覆盖当前 100 token、历史靠 self-attention 渗透，这保证音频对齐不会被压缩过的历史 token 污染。

音频编码
冻结 mHuBERT-147，全部隐层用可学习 softmax 权重融合，且 cross-attention 分支与全局条件分支各用一套独立的层融合权重；随后 kernel=5、stride=2 的一维跨步卷积 + LayerNorm 把音频序列对齐到动作帧率，产出 448 维音频 token。替代方案：只取最后一层特征——会丢掉跨语言音素信息，而自建数据含多语言来源。
时间对齐
cross-attention 用对角局部掩码：M_{i,j} = 0 当 |i−j| ≤ R，否则 −∞，R = 2 帧。每个动作 token 只关注对齐音频序列里的窄邻域，强化音素–口型的逐帧绑定。替代方案：全注意力——会允许远处音素「偷看」，降低唇同步精度并增加计算。
运动幅度条件
m = [m_r, m_t] ∈ [0,1]²，训练时由真值窗口的平均逐帧旋转位移（SO(3) 测地角）与平移位移幅值归一化得到。论文主张它比隐式风格特征可解释性与实用性更强，用于对抗「弱音频–动作相关导致的过平均」。替代方案：DiffPoseTalk / ARTalk 的风格嵌入——控制含义不透明，难以按用户需求调节。
主干结构
8 个 DiT 块 × 8 注意力头，模型维 448（头维 56）、MLP ratio 4（FFN 隐宽 1792），RoPE 旋转基 θ = 10000；末端 AdaLN 调制投影把 100 token 映回 115 维速度预测。

06 LS-state 与 Streaming Audio Scheduler：把轮替变成工程问题

听-说状态 q ∈ {−1,+1} 是这套系统的「挡位杆」。训练期它来自 TalkNet-ASD 的帧级说话置信度（短时平滑后二值化）；推理期它根本不需要推断——直接由音频来源决定：来自 LLM 的帧标 +1，来自环境/麦克风的帧标 −1。这是对「模式推断不可靠」问题的一个务实回答：把一个学习问题降级为一个调度问题。

图 4 · 调度器时间线：把「无缝轮替」具象化为三个分支的窗口合成问题——说话优先、缺口由最新倾听上下文补齐、拼接顺序尊重上一窗口尾模式以减小边界跳变。

论文对 Algorithm 1 的逐行逻辑是：先看说话队列未消耗长度 U；U ≥ T 则整窗说话；0 < U < T 则按 m_prev 决定 x_S 与 x_L 的拼接次序并用 LabelBySource 逐帧打 q 标签；U = 0 则整窗倾听。q 与 a 一起被发射，模型侧永远拿到模式已知的窗口——倾听阶段的嘴部幻觉因此被抑制，而切换点不需要任何未来信息。

深度洞察

「显式状态」是对生成模型不确定性的一种外置化

让网络从声学特征里猜「我现在该听还是该说」，本质是把一个系统级已知信息（音频是 LLM 产出的还是麦克风采集的）降级成统计推断。LS-state 的设计哲学与可控生成中的 classifier-free guidance、结构化控制信号一脉相承：凡是系统层面确定的事实，就不要让模型重新推断。消融数据支撑了这个判断：去掉 LS-state 后 MOD 从 1.99 升到 2.43，模型会把弱语音误判为倾听态并在不确定时张嘴；只加输入端状态 MOD 降到 2.10，再加 FiLM 才到 1.99——模式信号需要贯穿网络深度才能稳定行为。

07 两阶段训练：用图像域证据纠正 3D 跟踪偏差

单目视频估计出的 FLAME 参数不可避免地带噪有偏：遮挡、运动模糊、极端姿态下跟踪置信度低，纯系数空间监督会强迫模型拟合不可靠、甚至与图像证据矛盾的目标。EmbodiedHead 的应对是两阶段：Stage I 在系数空间用 flow matching 学稳定动力学（带分组加权与位姿平滑），Stage II 解冻渲染器、用图像域损失联合精调 DiT 与 GAGAvatar，让渲染器与生成动作分布互相适配。

图 5 · 两阶段因果链：Stage I 学「动起来像人」，Stage II 用渲染图像证据把「看起来像真的」拉回来，而 Rectified Flow 的直线路径是让这两者能对接的数学前提。
深度洞察

Stage II 的真正含义：把「伪真值」从监督目标降级为初始化

FLAME 跟踪参数是伪真值——它在遮挡与模糊帧上系统性偏离图像证据。Stage I 用它学动力学先验（它是合理的运动流形），Stage II 则让图像损失覆盖它：伪真值负责「像人」，像素证据负责「像这段视频里的这个人」。Fig. 6(a) 里优化后的网格比跟踪伪 GT 更接近真实张嘴细节，是一个反直觉但重要的结论：可微渲染 + 少步流匹配让生成模型有机会「超越」自己的监督标签。这也解释了为何 Stage II 后 PSNR 从 17.53 → 18.28、LPIPS 从 0.199 → 0.184（Tab.1 上半），而动作指标基本持平——它修的是渲染保真而非动力学。

08 实验与证据：附录里藏着的三个细节

主表之外，附录 C 的三组数据最值得精读。第一，推理步数表 S1 的「1†」设置：用与训练分布一致的随机时间步做单步生成，LVE 4.45 / FDD 0.85 / LPIPS 0.193，几乎全面优于固定 4 步（5.76 / 1.55 / 0.202）甚至 25 步——说明训练–推断时间步一致性比步数本身更关键，也直接验证了 Stage II 图像域精调的数学立足点。第二，运动幅度表 S2 的部分解耦：把 m_r 从 0.1 调到 0.9（m_t=0.1 时）实际旋转幅值从 0.50 升到 1.77、平移仅 0.88→1.07；反之亦然；GT 锚点为旋转 0.61、平移 0.81。第三，运行时分解：每个 100 帧窗口（25 FPS 下约 4 秒）音频特征 7.8 ms、4 步 DiT 动作生成 83 ms、GAGAvatar 渲染 1.69 s，调度器每 tick 0.029 ms。

批判评估

59 FPS 是「吞吐量」而非「响应延迟」

运行时分解揭示了瓶颈的真实位置：渲染 1.69 s / 100 帧 ≈ 59 FPS 的吞吐确实实时，但 100 帧窗口在 25 FPS 下约 4 秒——窗口化扩散天然带来时延下界，论文在附录 E 也自认「不像因果自回归架构，window-based 处理引入理论时延下界」。对对话式应用，用户感知的是「我话音落下到数字人开始回应」的延迟，而非 FPS。59 FPS 保证的是不掉帧，不保证低首响应时间。

批判评估

跨论文数字不可比：UniLS 在两篇论文里的两副面孔

EmbodiedHead 的表 1 里 UniLS 只有 LVE 12.73 / SID 1.57，而 UniLS 原论文在其自建 Seamless Interaction 测试集上报 LVE 5.83。原因是两者测试集、训练数据与渲染管线均不同（EmbodiedHead 在 DualTalk 训练集上重训各基线并统一过 GAGAvatar）。这提醒我们：talking-head 领域缺乏统一 benchmark 时，「SOTA」声明高度依赖评测口径，读者应以同表内相对差距而非绝对数值做判断。

批判评估

监听标签的天花板：ASD 二值化损失了多少信息？

训练期 LS-state 来自 TalkNet-ASD 置信度二值化，把倾听反应切成 {−1,+1} 两个挡位。但人类对话里「附和的嗯嗯声」「笑声」「抢话重叠」处于听与说的连续谱上，二值标签会在这些帧给出非此即彼的监督。论文的用户研究偏好率对 UniLS 最低（68.6% 起），或许正说明状态边界上的行为仍有提升空间。

09 深度洞察：三个设计哲学的交汇

深度洞察

评价口径对齐：让指标说「用户看到的话」

EmbodiedHead 反复强调的一个元问题是评价口径：3D 方法在系数空间报速度与精度，但用户消费的是渲染图像。论文的解法不只是「加了 PSNR/SSIM/LPIPS」，而是把渲染器纳入训练回路、并把所有基线统一过同一渲染管线再评——这让「画质」第一次成为 3D talking-head 路线内部可比的维度。对整个领域而言，这是一次从「动作像」到「画面像」的评测重心迁移。

深度洞察

三难问题的三角互换：少步生成换来了什么

实时、统一、高画质三者的耦合点其实是采样步数：DDPM 多步则不实时，单步则误差大到图像监督失效（MANGO 的困境）；双流需要未来信息则不因果。Rectified Flow 在这里不是「更快的扩散」，而是让「单步输出 = 推理输出 = 被监督的输出」三者重合的数学机制——只有这个重合成立，端到端图像域精调才不是自欺。可以说：直路径 → 单步端点可靠 → 图像域可监督 → 渲染质量可优化 → 少步可行 → 实时可行。

深度洞察

跨论文连接：与 UniLS 的「先验 + 调制」殊途同归

UniLS 把倾听行为分解为「内部运动先验 + 外部音频调制」，EmbodiedHead 则用「LS-state 模式门控 + 声学驱动」管理听-说切换。两者的共同直觉是：倾听不是音频的直接函数。UniLS 从生成分布角度把自由度还给先验，EmbodiedHead 从条件接口角度把模式外置。若把两者叠加——先验式倾听 + 显式状态门控 + 语义条件——可能是下一代听-说数字人的形态（详见第 10 章 Q3）。

10 自主科研问题

自主科研问题 · Q1

窗口化扩散的时延下界能否被「因果流式 Rectified Flow」打破？

未知与意义：论文自认 window-based 扩散存在理论时延下界（附录 E），但没有量化它。若能把直路径流匹配改造成逐帧因果的形式（如缓存历史速度场、块级自回归采样），实时数字人的首响应时间可从秒级降到百毫秒级，直接决定「对话感」。

理论分析：Rectified Flow 的单步端点估计依赖整窗 x_t 的联合去噪；把窗口切成因果块后，块间速度场是否仍近似直线、误差如何累积，是一个可分析的稳定性问题。可以形式化为块级 Lipschitz 常数与累积漂移的界。

连接：与 UniLS 的 chunk-based 自回归（其局限恰是「chunk 间细微不连续」）互为镜像：扩散有窗口延迟，自回归有块边界跳变——两者缺陷指向同一个「连续因果生成」空白。

探究方向：设计 AR–diffusion 混合结构（论文 future work 明确提到），在块内用少步流匹配保质量、块间用因果状态传递保连续；用「端点误差随块数累积曲线」作为核心评测。

自主科研问题 · Q2

LS-state 的二值边界能否推广为连续「听-说混合度」？

未知与意义：q ∈ {−1,+1} 无法表达附和声、笑声、抢话重叠等中间态；训练标签由 TalkNet-ASD 二值化而来，天花板受制于 ASD 模型本身。一个连续的「说话置信度 / 参与度」信号可能显著改善轮替边界的行为自然度。

理论分析：FiLM 调制 Â = A⊙(1+α(q)) + β(q) 对连续 q 天然兼容（α、β 是 q 的函数），形式上只需把离散嵌入换成连续标量嵌入；关键是损失如何约束连续标签的语义一致性，避免退化为无意义的灰度。

连接：这与语音合成中的 V/UV（浊音/清音）连续化、以及情感计算里的唤醒度–效价连续空间同构：从分类到回归往往带来行为细腻度的跃迁。

探究方向：用说话人分离 + 语音活动检测的软概率作为连续监督，对照二值 q 做消融，观测 MOD 与用户研究「轮替平滑度」偏好率的变化。

自主科研问题 · Q3

语义条件如何进入倾听反应，而不破坏实时因果性？

未知与意义：论文明确承认当前倾听行为由声学线索驱动、缺乏语义级对话理解（附录 E），无法做「点头表示同意」这类意图性反应。但 LLM 侧其实持有文本语义——如何在不引入未来信息的前提下把它注入倾听分支，是具身数字人从「会动」到「会意」的关键一步。

理论分析：语义 token 的更新频率（句级/轮次级）远低于动作帧率，适合走 AdaLN 全局条件通路做慢变调制，而声学走 cross-attention 做快变绑定；两者的时序尺度分离可避免语义信号污染逐帧口型。

连接：UniLS 的「先验 + 调制」框架同样缺语义（其局限表述几乎一致）；MM-Head 的文本条件、以及 LLM 的 token 流式输出（首个 token 到达即携带语义）提供了现成接口。

探究方向：构建「声学条件 vs 声学+语义条件」的对照实验，用语义恰当性人工标注（是否与对话内容匹配）作为新指标；探索 LLM 流式 token 的因果注入时刻对反应时延的影响。

自主科研问题 · Q4

图像域监督纠正跟踪偏差的机理边界在哪里？

未知与意义：Fig. 6(a) 显示 Stage II 后几何比跟踪伪 GT 更真实，说明 2D 监督能反向修正 3D 跟踪器偏差。但这种「超越标签」何时有效、何时会引入渲染器自身的伪影偏好，目前没有理论刻画——GAGAvatar 渲染细节本就少于高保真 avatar 管线（论文自述）。

理论分析：可把问题看成带系统性噪声标签的回归：伪真值 = 真值 + 跟踪偏差 b(x)，图像损失提供对 b(x) 的间接观测。当渲染器表达能力受限时，联合优化可能收敛到「渲染器擅长的几何」而非真实几何——这是一个可构造反例的双优化偏差问题。

连接：与半监督/弱监督学习中「用教师伪标签初始化、用真实信号精调」的范式相通；也呼应 Neural Rendering 中 appearance-geometry 歧义的经典难题。

探究方向：在合成数据（已知真值几何）上量化 Stage II 前后几何误差，扫描渲染器容量与 λ_coef 权重，画出「何时修正、何时过拟合渲染器」的相图。

# Streaming Audio Scheduler（依 Algorithm 1 重写；T=100 帧 @25FPS）
def schedule_window(Q_L, Q_S, c_L, c_S, m_prev, T):
    # Q_L: 麦克风滚动缓冲（倾听）; Q_S: LLM 说话单调消耗队列
    U = get_unconsumed_length(Q_S, c_S)
    if U >= T:                        # 说话队列单独填满窗口
        a = slice_head(Q_S, c_S, T)
        q = +ones(T)                  # 整窗 q=+1（说）
        c_S += T; m_prev = "speak"
    elif U > 0:                       # 部分说话：用倾听尾部补齐
        x_S = slice_head(Q_S, c_S, U)
        x_L = slice_tail(Q_L, T - U)
        a = (x_S + x_L) if m_prev == "speak" else (x_L + x_S)  # 保时序连续
        q = label_by_source(a)        # 按来源逐帧打 ±1
        c_S += U
        m_prev = "listen" if m_prev == "speak" else "speak"
    else:                             # 纯倾听
        a = slice_tail(Q_L, T)
        q = -ones(T)
        m_prev = "listen"
    return a, q                      # 波形 a 与 LS-state q 一起发射
[示意性实现]
# Rectified-Flow DiT 少步采样 + Stage-II 单步端点图像监督（依 Eq.2/5/7/8 重写）
def rf_sample(cond, steps=4):
    x = randn(T, 115)                              # x0 ~ N(0, I)
    ts = linspace(1.0, 0.0, steps + 1)
    for t, t_next in pairs(ts):
        v = dit(x, t, film_audio(cond.audio, cond.q))  # Eq.5: A*(1+alpha(q))+beta(q)
        x = x + (t_next - t) * v                     # Euler 沿直路径积分
    return x                                        # 4 步默认配置

def stage2_loss(x_t, t, cond, gt_img):
    # 直路径性质：单步端点即推理输出，图像损失锚定真实采样结果
    v = dit(x_t, t, cond)
    x1_hat = x_t + (1.0 - t) * v                     # Eq.7
    img_hat = gagavatar_render(x1_hat, cond.shape)   # R(x̂1, s), 256x256
    L_I = grouped_flow_matching(v, cond.x1, cond.x0)  # Eq.6: lambda_expr=0.6 等
    L = 0.2 * L_I + lambda_img * (
        0.2 * l1(img_hat, gt_img) +
        0.2 * lpips(img_hat, gt_img))                # Eq.8 权重（附录 B.1）
    return L

关键细节对照：per-token 输入 116 维（115 动作 + 1 个 LS-state 通道）；self-attention 序列 120 token（20 打包历史 + 100 当前）；FiLM 与 AdaLN 调制层均零初始化，保证训练从恒等映射起步；推理默认 4 步 Euler、运动幅度引导 0.3。
