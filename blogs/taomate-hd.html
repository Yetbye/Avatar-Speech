01 一句话读懂 & 问题动机

TaoMate-HD 要解决的是流式数字人（streaming digital human）的两难：高分辨率去噪太贵，而文本一更新就容易重复或打断正在说的话。它的核心解法是「渐进分辨率的自回归生成」——每个 chunk 用两步低分辨率去噪先立住画面结构，最后一步才升到高分辨率精修，音频则在同一条轨迹上全程生成；更关键的是，每个阶段的干净音视频预测直接作为下一 chunk 同阶段的历史，于是后一个 chunk 不必等前一个 chunk 精修完就能开工。

问题的来源很具体。交互式数字人需要在新对话文本陆续到达时持续说话、持续动。直接高分辨率生成在每一步去噪都铺满稠密的视频 token 网格，哪怕早期步骤其实只在确定场景布局与大尺度运动；少步蒸馏（few-step distillation）减少了步数，但没减少每步的空间开销；而且「单个 chunk 变快」并不消除 chunk 之间的等待——若下一 chunk 必须以上一 chunk 的最终输出为历史，就必须等全部精修结束。另一方面，流式文本更新常常在句子中间到达，且文本窗口边界与句子结尾不对齐：从头重说会重复已说内容，停在窗口边界会打断话语。模型因此需要从最近音频里推断「已经说到哪了」。

论文的三条贡献对应三个抓手：（1）渐进式音视频生成器，把去噪集中在粗网格上，阶段局部（stage-local）的历史让 chunk 之间可以重叠执行；（2）带非对称文本条件的续说训练（asymmetric text conditioning + student-generated history），支持跨重叠文本窗口的语音续说；（3）小时级高分辨率演示与量化对比。量化结果：同等模型与硬件下渐进式比直接高分辨率生成快 1.60×（论文表述，491s → 307s 平均生成时间），优化的阶段并行部署再快 1.92×（307s → 160s），续说训练把字符错误率 CER 从 30.75% 降到 19.57%（约 11.18 个百分点）。

深度洞察

「不等精修完就交接历史」是这篇论文真正的杠杆

渐进分辨率本身并不新（pyramidal flow、Matryoshka diffusion 都在做多尺度生成），TaoMate-HD 的增量在于把「中间估计」升级为可交接的一等公民：每个阶段在 σ=0 处把干净估计编码成该阶段原生网格上的 KV，交给下一 chunk 的同一阶段。这把「分辨率调度」和「时序并行」两件原本独立的加速手段焊在了一起——正因为早期阶段只要粗网格历史，下一 chunk 才能提前进入粗阶段。换句话说，空间上的「先粗后精」换来了时间上的「流水线重叠」，这是设计上的耦合收益，而非两个 trick 的简单叠加。

02 范式定位：从固定分辨率串行到渐进分辨率阶段并行

把 TaoMate-HD 放进谱系里看，它同时对抗三条路线的短板：少步蒸馏（CausVid、Self Forcing 一系）减少采样步数但每步仍是满格网格；渐进空间计算（Matryoshka diffusion、pyramidal flow、PyramidalWan）沿轨迹改变分辨率，但多在单段生成内、不解决跨 chunk 的历史供给；阶段并行推理（HiAR 一系的反斜线流水线）让 chunk 与去噪阶段重叠，但要求在最终输出之前就拿到可用的音视频上下文。论文对 HiAR 的关键差异化表述是：HiAR 的阶段历史以「该阶段输出噪声水平」表示，而 TaoMate-HD 用成对的干净音视频预测（clean prediction）在各阶段原生网格上表示历史——干净预测是跨阶段的公共历史表示，尽管查询的噪声水平与空间网格各不相同。

图 1 · 范式对比：把「等待最终输出才能续写历史」的串行范式，换成「阶段局部干净预测即历史」的反斜线流水线——这是本文把抽象的时空权衡具象化的核心图。
与少步蒸馏的关系
少步蒸馏（CausVid、Self Forcing）把采样压到 3–4 步，但每步仍是满格计算；TaoMate-HD 的 N=3 是空间上的渐进调度，与步数压缩正交、可叠加。替代方案：继续压步数到 1 步（DMD 系），但早步布局质量与高分辨率成本仍未解。
与阶段并行（HiAR）的关系
借用其「chunk × 阶段反斜线」执行组织，但把阶段历史从「带噪表示」换成「干净 AV 预测 + 各阶段原生网格 KV」，并保留音频的原生 latent 几何。替代方案：等最终输出再写历史——流水线退化为串行。
与事后超分（Ultra Flash 一类）的关系
TaoMate-HD 在联合音视频轨迹内部改分辨率，而非在生成完成后用独立生成器精修输出，因此中间 AV 预测可同时充当历史。替代方案：独立因果超分模块，管线更解耦，但无法提供跨 chunk 的早期历史。
与 TaoMate（前作）的关系
TaoMate 用不可变视觉锚 + 自适应音视频记忆 + 活跃 KV 做长程一致性，但阶段并行推理在固定空间分辨率下进行；TaoMate-HD 把渐进分辨率引进来，并以「成对干净 AV 预测」统一各阶段历史表示。

03 系统分解：一个 chunk 内的三阶段与跨 chunk 的阶段交接

方法主干是粗到细去噪 + 阶段局部 KV 历史。对 N 步轨迹，前 N−1 次评估在低分辨率视频网格 L 上完成，最后一次评估在高分辨率网格 H 上完成；音频保持相同的 latent 几何，因此「视频精修」和「音频生成」仍是同一条联合轨迹。论文实例化 N=3：网格 L=480×864、H=768×1376（图示 token 网格 15×27 与 24×43）。每个 chunk 的评估次数是 3 次去噪 + 3 次干净历史编码；作为对照，MiniMax-H3 每个 5 秒请求用 49 次去噪评估，VDN 用 8 次，Lynn 系列每个自回归窗口用 4 次或 3 次（论文表述）。

图 2 · 把「自回归历史」拆成阶段局部的 KV 银行：每阶段在 σ=0 处把干净估计编码成本阶段原生网格的 KV，交给下一 chunk 的同一阶段——这一步把「中间预测」变成了可复用的上下文。
深度洞察

为什么「干净预测」是比「带噪状态」更好的跨 chunk 历史

不同阶段的查询噪声水平 σ_ℓ 与空间网格（L/H）都不同，若历史以带噪状态表示，各阶段之间并不可比。干净预测 x̂ = u + σ·v̂ 估的是零噪声端点，是一个与查询噪声水平解耦的公共表示：粗阶段的历史可以在粗网格上编码，最终阶段的历史在 H 网格上编码，但语义都是「这一段 AV 长什么样」。这解释了论文为什么强调与 HiAR 的差异——它换的不只是执行调度，而是历史的表示坐标系。

文本窗口更新则是一次「不重编码过去」的切换（Algorithm 1）：先把挂在旧窗口 c_G(old) 下的待决干净预测提交掉；保留首 chunk 视频 KV 与最近两 chunk 成对 AV；再激活新窗口并刷新缓存的文本投影，而已保留 KV 及其时间位置原封不动。于是新文本只控制未来的合成，无需重编码已生成的过去；空间坐标留在各网格原生坐标系，时间位置跨窗口延续。训练时使用同样的更新顺序，只是保留短 rollout 的完整因果前缀。

04 关键公式：干净端点估计与耦合的跨分辨率提升

整条轨迹采用流匹配（rectified flow）参数化 u^σ = (1−σ)·x_clean + σ·ε，生成器预测的速度场估计 x_clean − ε。由此每个阶段的一次评估同时给出欧拉推进（给本 chunk 用）和干净预测（给下一 chunk 用），系数完全由噪声水平差 σ_ℓ − σ_{ℓ+1} 与当前 σ_ℓ 决定。

Eq.1 · 一次评估的双重产出（式 1，系数按原文核对）
$$ \tilde u^{m}_{b,\ell+1} = u^{m}_{b,\ell} + (\sigma^{m}_{\ell} - \sigma^{m}_{\ell+1})\,\hat v^{m}_{b,\ell}, \qquad \hat x^{m}_{b,\ell} = u^{m}_{b,\ell} + \sigma^{m}_{\ell}\,\hat v^{m}_{b,\ell} $$
直觉：m ∈ {v, a} 表示视频/音频模态，b 为 chunk，ℓ 为阶段，σ^m_ℓ 是递减的噪声水平且终点 σ^m_{N+1}=0。左式是标准 Euler 更新（把当前速度乘以噪声区间长度）；右式把当前状态沿速度回推到 σ=0 的干净端点——不执行剩余阶段就能拿到历史。在最终阶段两者重合，因为下一噪声水平就是 0。

跨到 H 网格时有个容易被忽略的陷阱：直接插值会把残余噪声相关化，而高分辨率轨迹需要标准高斯噪声。论文的做法是耦合噪声：取 ε_H ~ N(0, I)，令低格噪声 ε_L = P·ε_H，其中 P·Pᵀ = I 保证 ε_L 仍是标准高斯；再用双线性插值 U 做信号搬运，只把「插值出来的噪声」换成耦合的高格噪声。

Eq.2 · 耦合提升 Λ_σ（式 2，系数按原文核对）
$$ \Lambda_{\sigma}(u_L) = U(u_L) + \sigma\left[\epsilon_H - U(\epsilon_L)\right], \qquad \epsilon_H \sim \mathcal{N}(0, I),\ \epsilon_L = P\,\epsilon_H,\ P P^{\top} = I $$
直觉：U(·) 是双线性插值。第一项搬运信号，第二项把插值噪声替换为耦合的高格噪声，从而保住「信号/噪声」分解不被破坏。用在最终阶段入口：u^v_{b,N} = Λ_{σ^v_N}(ũ^v_{b,N})；音频不做此空间过渡，原样通过。P 的正交约束是关键系数条件，否则 ε_L 不再标准高斯、低格轨迹分布被污染。
Eq.3 · 阶段依赖结构（式 3）
$$ \mathrm{T}_{b,\ell} \leftarrow \{ \mathrm{T}_{b,\ell-1},\ \mathrm{T}_{b-1,\ell} \} $$
直觉：阶段 ℓ 的 chunk b 依赖「本 chunk 上一阶段」与「上一 chunk 同阶段」两个来源。这个二维依赖图正是反斜线（anti-diagonal）阶段并行推理合法性的来源：后 chunk 可以占据粗阶段，同时前 chunk 进行最终精修。在文本窗口内，粗阶段把「上一 chunk 干净估计的编码」与「当前噪声 chunk 的去噪」融合：因果掩码让噪声 chunk 读到该估计与更早历史，而上下文 chunk 只读历史与自身。
深度洞察

Eq.2 揭示的通用教训：升分辨率不等于升采样

扩散/流模型社区常把「低分辨率生成 → 上采样 → 高分辨率续跑」当作纯工程步骤，但 Eq.2 说明这里有一个分布层面的正确性条件：噪声必须在两个网格上联合耦合。若残余噪声被插值相关化，高分辨率阶段看到的就不再是 N(0, I) 的噪声边际，去噪器的训练分布被破坏。这个「同噪声、不同网格」的技巧（论文用 P·Pᵀ=I 的正交映射实现）可迁移到任何 latent 级渐进采样器，也解释了为什么朴素双线性上采样续跑常出现纹理脏化。

05 非对称蒸馏：让模型学会「接着说」而不是「重新说」

续说（continuation）问题的结构是：文本更新常在句子中途到达，窗口边界与句尾不对齐，且新窗口里包含已说过的词。论文用重叠文本窗口建模：设 A 为较早文本、B 为共享跨度、C 为新台词；生成器从 W₁ = A+B 切到 W₂ = B+C，保留历史，把 B 当作上下文而非重新开始。推理时模型只靠音频历史与文本隐式判断说话进度——没有 ASR、没有文本指针、没有对齐模块。

图 3 · 把「续说」这个抽象的语言学问题具象化为窗口重叠问题：B 跨度既在旧窗口里是待说内容，又在新窗口里是已说上下文，模型必须靠音频历史区分两者。

训练在学生自生成 rollout上进行（Self Forcing 一系）：学生执行全部 N 个阶段、更新自己的历史银行、在一个采样出的 chunk 边界切换文本。窗口构造时用同主题语音扩展源转写，保留原文措辞、语种与说话人分配；源语速把名义时间区间映射到字符/词跨度；初始窗口 A+B 覆盖整个名义 rollout 长度，即使切换提前发生。监督采用分布匹配蒸馏（DMD）：冻结教师分数 vs 学生分布的可学习分数，两者吃同一音视频序列、同一腐蚀噪声、同一噪声水平，因此差值在共同噪声态上定义 DMD 更新。三个角色的文本条件刻意不对称：

角色文本条件作用
Generator（生成器）切换前 W₁，切换后 W₂需要 W₂ 才能续写下一段；B 作为上下文而非重说
Fake score（可学习分数）保留 W₁（含 W₂ 缺失的开头词 + 扩展台词）从脱离梯度的学生序列做速度回归（独立噪声抽样）学习学生分布
Real score（冻结教师）原始源转写前缀（截至 rollout 时长）把教师参照系锚回源片段，扩展台词只当生成前瞻（lookahead）

为覆盖每个精修级别，训练每个 rollout 采样一个阶段（跨 chunk 共享同一阶段，保证序列精修级别一致），把其干净预测跨 chunk 拼成序列。粗阶段的干净视频 latent 用双线性插值放大到 H，时间、通道与音频不动——给两个分数一张共同的高分辨率监督画布；学生仍按各阶段原生网格去噪，所以「放大预测来打分」让高分辨率教师能监督粗阶段而不改变其计算分辨率。梯度实现是「先无梯度构造 rollout，再逐 chunk 重放选中评估」：重放预测替换到脱离梯度画布上对应区域，chunk 掩码把更新限制在该区域，分数保有全序列上下文，而梯度只流经活跃预测及其空间插值。另有一个辅助教师目标强化最终阶段细节：冻结基座模型从学生的提升状态出发、以之前最终干净 AV chunk 为条件去噪到端点，学生最终视频预测向其回归。

深度洞察

「不对称」的实质：让三个角色各自站在正确的时间锚点上

生成器站在未来（要 W₂ 才能续说），fake score 站在学生实际走过的轨迹（必须保留 W₁ 才能描述学生生成了什么），real score 站在源数据的真值锚（只看源前缀，防止扩展台词把教师目标带偏）。如果三者共享同一文本（消融组的做法），教师的「正确答案」与学生的「实际输出」在文本上就错位了——这正是消融里 CER 高达 30.75% 的结构性原因之一。这是一种把因果角色差异显式编码进条件的蒸馏设计，值得迁移到任何「条件在中途变化」的自回归蒸馏场景。

06 长流推理与语音收尾：不只有「怎么说下去」，还有「何时停」

长流（hour-long）推理的关键在记忆的固定容量：每个 KV 银行只保留首 chunk 视频作视觉锚（锚定人物外观与场景构图）+ 最近两 chunk 的成对音视频（携带近期说话上下文），初始音频只要还在这个近期窗口内就可用。KV 与缓存的文本投影分开存储：文本窗口切换只刷新后者，保留的 KV 仍按其原始条件编码——这正是「新文本控制未来、无需重编码过去」的实现基础。论文报告了两条 60 分钟、1376×768 的音视频流，在标注时间点采样的全帧保持了人物外观与场景构图（论文表述，见其 Figure 1 底部）。

图 4 · 因果链：固定容量的 KV 银行同时承载「外观锚定」与「说话进度推断」，而语音收尾通过端点确认的训练样本显式覆盖——把「何时停」纳入训练分布而非指望涌现。
记忆与锚
不可变视觉锚（首 chunk 视频）+ 自适应 AV 记忆（最近两 chunk）+ 活跃 KV，分离存储。替代方案：全局缓存全部历史——随流长线性增长，且长程注意力成本上升。
训练与前置
从 MiniMax-H3 FL2VA 模型出发，用 rank-128 LoRA 在 10,000 组自建蒸馏对上训练；评测含 100 条 1–10 分钟自建序列（每条由连续的 5 秒文本请求构成），输出 768×1376 @ 24 FPS、32-kHz 立体声。
文本切换协议
Algorithm 1 五步：提交旧窗口待决干净估计 → 保留锚与最近两 chunk → 激活新窗口、刷新文本投影 → 保留 KV 与时间位置 → 用新条件去噪下一 chunk。替代方案：切换时重编码全历史——正确但延迟不可接受。
部署与并行
阶段并行部署叠加：阶段重叠、低阶段融合、KV 复用、选择性 W8A8 投影、不同注意力实现、编解码调度（论文表述为部署级组合优化）。

07 证据：速度从哪来，质量守住了吗

08 深度洞察 & 批判评估

深度洞察

用「生成看未来、打分看过去」破解条件漂移

非对称蒸馏最漂亮的一步是承认一个事实：描述学生分布的分数必须保留学生当时看到的全部条件（W₁），而驱动生成的条件可以前进（W₂）。这在数学上是必要的——fake score 学的是学生实际生成序列的分布，若条件文本与学生当时不同，速度回归学到的就是一个从未被采样过的条件分布。这一「生成条件 ≠ 评分条件」的分离，比调重叠窗口长度更本质，也是该方法能同时降替换（−12.64pp）与删除（−1.28pp）错误的结构性原因。

深度洞察

干净预测作为「跨阶段通用货币」，是可迁移的设计模式

任何多阶段/多尺度生成器都面临「中间产物能否喂给下游」的问题。TaoMate-HD 的答案是：把中间产物投影到零噪声端点，使其脱离查询噪声水平与网格的耦合。这可迁移到：级联超分的中间层交接、多模态 DiT 中某模态先行供给另一模态、以及推测解码（speculative decoding）里草稿模型向目标模型交接中间状态——共同点是都需要一个与「当前进度」解耦的规范表示。

批判评估

四个必须摆在桌面上的代价

① CER 19.57% 仍是高错误率。组内最低不等于可用：替换错误虽降 12.64pp，插入错误反而升 2.74pp，说明续说模型偏「多说」（重复/赘语方向），这对数字人产品是可感知的瑕疵。② 1.92× 部署加速无法归因。论文自己说明该对比是部署级组合（阶段重叠 + 低阶段融合 + KV 复用 + 选择性 W8A8 + 不同注意力实现 + 编解码调度），各因子贡献未拆分，其中 W8A8 量化对质量的影响也未单独报告。③ 口径不齐削弱 22.4× 的说服力。本文计时区间是「准备输入→解码 AV」，对照组含在线条件化与编码/封装；且已发表速率是在 768×512 的不同分辨率口径上测的（论文表述）。④ 质量代价集中在细粒度。Video 0.85 vs Direct 768p 的 0.87、LSE-C 6.34 vs 6.62、Long-range 0.930 低于 TaoMate 的 0.983、并行配置 CER 21.28% 略劣于串行 19.57%——渐进调度不是全无代价，只是代价可控。此外评测仅 100 条自建序列、无显著性检验、CER 只覆盖中文语音（排除不支持中文的方法），泛化性证据有限。

批判评估

隐藏前提：一切建立在「学生 rollout 分布」之上

续说训练在学生自生成序列上进行，这消除了训练/测试失配（Self Forcing 的立意），但也把误差闭环了：若学生早期 rollout 系统性偏航（例如某类口音/语速下进度推断失灵），训练分布里就没有纠偏信号。论文的收尾样本（端点由转写 + 时间戳 ASR + VAD 离线确认）只覆盖「说完→停」这一种边界，对中途打断、换说话人、语码切换等交互场景未见证据。隐式进度推断（无 ASR/指针）优雅，但其可辨识性没有被分析——两个不同的说话进度可能产生相似的近期音频。

09 自主科研问题

自主科研问题 · Q1

阶段局部 KV 银行的最优容量与遗忘策略是什么？

未知与意义：论文固定「首 chunk 视觉锚 + 最近两 chunk 成对 AV」，这是工程选择而非推导结果。若最近窗口过短，长程语音语调漂移；过长则固定容量的意义消失。最优遗忘边界在哪里，直接影响小时级一致性与显存预算。

理论分析：可把 KV 银行视为一个固定容量的有损信源编码问题：历史 AV 流以有限槽位压缩，重建目标是「外观 + 说话进度」两个下游任务的联合保真。视觉锚承担低频（外观）分量、近期窗口承担高频（语流）分量，近似一个显式的两级记忆分解。

连接：与 VideoSSM/TetherCache/SlotMemory 等长视频记忆工作（论文引用 [28–30]）、KV cache 淘汰（H2O/StreamingLLM 的注意力汇）、以及状态空间模型的固定容量递归状态直接对话。

探究方向：做「槽位数 × 锚策略」网格消融（1/2/4 个近期 chunk；锚可更新 vs 不可变），度量 LSE-C、MFCC 端点一致性与 30 分钟后外观漂移；再试按注意力质量加权的软淘汰，验证固定容量下是否存在清晰的容量-质量拐点。

自主科研问题 · Q2

耦合噪声提升（Eq.2）中 P 与 U 的选择对生成分布的影响有多大？

未知与意义：论文用正交 P（P·Pᵀ=I）与双线性 U，保证低格噪声标准高斯。但 P 的具体正交基、U 的插值核都非唯一，它们决定了「插值噪声残差」ε_H − U(ε_L) 的谱形状，进而影响高分辨率阶段看到的噪声分布。这直接关系渐进式生成的纹理质量上限。

理论分析：Λ_σ 的修正项等价于把噪声边际精确恢复为 N(0, I) 而保留信号项；不同 U 改变的是残差噪声的空间相关长度。若残差相关长度偏离训练分布，去噪器会把相关纹理误判为信号，产生重复纹理或过度平滑。

连接：与信号处理中的噪声整形（noise shaping）、图像上采样的核设计、以及扩散模型的噪声先验（如 EDM 的 σ-dependent 预条件）相连；也关系 Video DeltaNet 等改注意力结构工作对空间相关性的假设。

探究方向：固定其余变量，扫描 U ∈ {双线性、bicubic、最近邻} 与 P 的构造（随机正交 vs 频域分块），度量 Video/LSE-C 与频谱统计（对比 Direct 768p 的功率谱）；并验证「残差相关长度与训练噪声一致」是否是渐进式生成质量的充分条件。

自主科研问题 · Q3

重叠窗口 B 的长度与 CER 误差类型之间的定量律是什么？

未知与意义：消融显示非对称蒸馏让插入错误上升 2.74pp、替换/删除大幅下降。一个自然猜想是：B 越长，续说锚越强、重复越多。若存在定量律，就能按场景（客服 vs 讲解）调窗口策略，而不是全用同一重叠率。

理论分析：B 兼具「待说内容」与「已说上下文」双重身份，模型对 B 中词的说话进度推断是一个隐式贝叶斯去卷积问题：后验不确定度越高，模型越倾向「保守多说」（插入错误）或「跳过」（删除错误）。错误类型分布可能正是进度推断不确定度的可测代理。

连接：与语音识别的端点检测/VAD 不确定度、同声传译的 ear-voice span（翻译延迟）研究、以及 LLM 指令跟随中的重复（repetition）文献相通。

探究方向：构造受控实验：固定训练配置，推理时扫描 B/A 比例与切换位置（句中 vs 句尾），记录插入/替换/删除三类错误与切换延迟；再用音频历史的探针分类器估计进度推断不确定度，检验其与插入错误率的相关性。

自主科研问题 · Q4

干净估计作为历史，误差如何在自回归链上累积？

未知与意义：每 chunk 的历史来自 σ=0 处的预测端点而非真实去噪完成值——粗阶段的 x̂ 本身就是早期估计。若估计误差经 KV 链条自回归放大，小时级流的后段质量会缓慢劣化；论文的 MFCC 端点一致性（0.979）只度量单条序列首尾，未直接追踪误差传播。

理论分析：这构成一个带反馈的误差动力系统：第 b 段历史误差 e_b = f(e_{b−1}) + ξ_b，其中 ξ 是本段估计噪声。若 |∂f/∂e| < 1 系统稳定（误差饱和），否则沿链放大。最终阶段 bank 存高分辨率端点、粗阶段 bank 存粗估计，两级的增益可能不同。

连接：与自回归生成的曝光偏差（exposure bias）、循环状态空间模型的稳定性分析（收缩映射/Lyapunov 指数）、以及 Kalman 滤波中预测-更新的误差协方差演化相连。

探究方向：人为注入可控历史扰动（对 KV 加噪/替换），测量后续 20 段的 Temporal/Long-range/LSE-C 衰减曲线，估计经验增益；比较粗阶段历史 vs 最终阶段历史的增益差，验证「干净端点预测是否真的实现了 f 的收缩」。

[示意性实现]
# 渐进分辨率三阶段去噪 + 阶段局部干净历史（对应 Eq.1 / Eq.2 / Eq.3）
def progressive_chunk(gen, u, cond_text, history_banks, sigmas, grids):
    # u: 含噪音视频 latent (v, a)；sigmas: [s1, s2, s3, 0]；grids: [L, L, H]
    N = len(sigmas) - 1
    clean_av = {}
    for ell in range(N):
        # 依赖式 T(b,ell) <- {T(b,ell-1), T(b-1,ell)}：读本 chunk 上一阶段 + 上一 chunk 同阶段 KV
        kv_ctx = history_banks[ell].read(current_prev_stage=clean_av.get(ell - 1))
        v_hat = gen(u, cond_text, kv_ctx)                    # 速度场估计 x_clean - eps
        u_next = u + (sigmas[ell] - sigmas[ell + 1]) * v_hat   # Euler 更新（式 1 左）
        x_clean = u + sigmas[ell] * v_hat                    # 干净端点预测（式 1 右）
        clean_av[ell] = x_clean
        # 干净预测以 sigma=0、本阶段原生网格编码，交下一 chunk 同阶段
        history_banks[ell].commit_encode(x_clean, sigma=0, grid=grids[ell])
        if ell == N - 2:                                   # 进入 H 网格前：耦合提升（式 2）
            u_next = coupled_lift(u_next, sigma=sigmas[ell + 1])
    return u_next, clean_av

def coupled_lift(u_L, sigma, eps_H, P, U):
    # eps_H ~ N(0, I)；eps_L = P @ eps_H，P P^T = I 保证 eps_L 标准高斯
    eps_L = P @ eps_H
    return U(u_L) + sigma * (eps_H - U(eps_L))
[示意性实现]
# 文本窗口边界更新（Algorithm 1）与非对称 DMD 三角色条件（示意）
def switch_text_window(banks, pending_clean, old_cond, new_cond):
    if pending_clean is not None:
        banks.commit(pending_clean, cond=old_cond)      # 1. 旧窗口下提交待决干净估计
    banks.keep(initial_video_kv=True, recent_av=2)        # 2. 锚 + 最近两 chunk 成对 AV
    text_proj = refresh_text_projections(new_cond)      # 3. 激活新窗口，只刷文本投影
    banks.preserve_kv_and_positions()                   # 4. KV 与时间位置原封不动
    return text_proj

def asymmetric_dmd_loss(student_rollout, W1, W2, source_prefix):
    # 生成器：切换后用 W2 续说；B 作上下文而非重说
    gen_out = student.generate(cond=W2, history=student.history_banks)
    # fake score 保留 W1（含 W2 缺失开头词 + 扩展台词）：描述学生真实分布
    fake = score_net(student_rollout.detach(), cond=W1, noise=independent_draw())
    # real score 只看源转写前缀：教师锚回源片段
    real = frozen_teacher(student_rollout, cond=source_prefix, noise=same_noise)
    dmd = real.velocity - fake.velocity                 # 共同噪声态上的 DMD 更新
    # 每 rollout 采样一个阶段，其干净预测插值到 H 打分；chunk 掩码限制梯度区域
    return masked_replay_loss(dmd, selected_stage, resize_to_H=True)
