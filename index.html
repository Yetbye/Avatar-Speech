白板的两条主轴：S+A 对齐 vs 任务角度

白板把「speech-audio alignment（S-A 对齐）」与「task angle analysis（任务角度）」并列为核心分析维度：前者关乎 Latent / 时间 / 声画同步的对齐粒度（shared DiT、Bridge、对比对齐、Aligned RoPE），后者关乎把生成拆成 A/S/V 任务后如何调度训练与损失（60% Audio / 40% Speech 的 A 分布、into loss / delay、loss function / reward）。
